Supported browsers

Strivo runs in current versions of the major browsers. If Strivo told you your browser could not run it, updating to the latest version of the browser you already use is almost always enough.

Versions we build and test for

Browser Version
Chrome, Edge and other Chromium browsers 100 or newer
Firefox 114 or newer
Safari and Safari on iPhone or iPad 15.4 or newer
Opera 86 or newer

These are guidance, not a hard cut-off. Strivo works out what it can do by checking what your browser can actually do, so an older browser may still work for most things, and a newer one may still have a feature turned off if it is set up to block something Strivo needs.

If updating is not an option

Some browsers are managed by an employer or a school and cannot be updated by the person using them. In that case, opening Strivo in a different, current browser on the same device usually works. Turning off strict privacy settings, or allowing site data for Strivo, also resolves most limits.
