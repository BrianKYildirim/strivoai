## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03 | Elevation of Privilege | unauthenticated checkout creation | mitigate | `requireAuth(req, { type: 'user' })` gates every request; returns 401 on missing/invalid JWT. Rate-limiter gates abuse by authenticated users. |
| T-07-04 | Elevation of Privilege | client-side tier promotion via priceId | mitigate | Input contract is `{tier, interval}` ONLY. Allowlist check rejects anything else with 400. Price ID resolved server-side from `STRIPE_PRICE_<TIER>_<INTERVAL>` env var. Grep gate on `body.priceId` keeps future diffs honest. |
| T-07-06 | Spoofing | cross-origin checkout from malicious site | mitigate | `handleOptionsRequest({ type: 'user' })` + `corsHeaders({ type: 'user' })` enforce `APP_URL` allowlist (fail-closed per existing `_shared/cors.ts`). |
| T-07-07 | Information Disclosure | error responses / logs | mitigate | Error messages are operational (`invalid_tier`, `price_not_configured`) — no secret leakage. `STRIPE_SECRET_KEY` never logged. `createLogger('create-checkout-session')` uses reason codes. |
| DoS via checkout spam | DoS | authenticated abuse | mitigate | `checkRateLimit` with per-tier hourly limits (free 10 / pro 30 / elite 60). |
</threat_model>
