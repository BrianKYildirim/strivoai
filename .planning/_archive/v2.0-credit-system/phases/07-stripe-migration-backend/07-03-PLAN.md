<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Stripe → webhook | Untrusted HTTP payload crosses here; signature is the only credential (no JWT) |
| webhook → profiles | Service-role update writes subscription_tier — tier elevation surface |
| webhook → stripe_webhook_events | Idempotency store; duplicate-event replay surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Spoofing | `stripe-webhook` signature verify | mitigate | `stripe.webhooks.constructEventAsync(rawBody, signature, webhookSecret, undefined, cryptoProvider)` — HMAC-SHA256 over raw body from `req.text()` before any parse. Reject with 400 on throw. Missing header/secret → 401. No hand-rolled HMAC anywhere (enforced by grep gate on `crypto.subtle.sign`). |
| T-07-02 | Tampering / Replay | `stripe_webhook_events` idempotency | mitigate | Single `INSERT` on `event_id PRIMARY KEY`, catch `23505` → 200 duplicate. Atomic — no select-then-insert race. Additionally, Stripe SDK enforces 300s timestamp tolerance by default in `constructEventAsync`. |
| T-07-04 | Elevation of Privilege | Tier resolution via price map | mitigate | `subscription_tier` is written ONLY from `resolveTier(priceId)` which reads a fixed env-var map. Unknown priceId → `'free'` (fail-low). Stripe webhook never accepts a tier value from any external source. |
| T-07-05 | Information Disclosure | `stripe_webhook_events` table | mitigate | Insert uses service-role client; RLS has no permissive policies (verified in Plan 02). Payload contains customer metadata but is unreadable via anon/auth JWT. |
| T-07-07 | Information Disclosure | structured logging | mitigate | Never log `webhookSecret`, `STRIPE_SECRET_KEY`, full `payload`, or raw customer email bodies. Use reason codes (`signature-verify-failed`, `profile-not-found`, `unknown-price-id`). |
| Replay storm DoS | Denial of Service | unhandled event types | mitigate | Unknown events return 200 + log (D-12) — Stripe does not retry. Missing profile lookups also return 200 (D-17) to stop retry storms. |
</threat_model>
