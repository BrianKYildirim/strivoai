<objective>
Extend `supabase/functions/_shared/merit-gateway.ts` so `withMerits` accepts an optional 4th `options?: MeritGatewayOptions<T>` parameter with a `precheck_cache` callback. When the callback returns a hit, the gateway short-circuits — skips rate-limit (CACHE-09 bypass — D-15), skips the deduct RPC, writes a `usage_tracking` row with `credits=0` + `analysis_id` (CACHE-10 / D-13), and returns the cached value with `transactionId: 'cache-hit'` sentinel. When the callback returns null (or throws), the gateway falls through to the existing rate-limit → deduct → fn flow unchanged.

Purpose: CACHE-09 (cache hit short-circuits merit deduct) + CACHE-10 (cache hits surface in Activity History) + CACHE-11 (user-scoped — user_id is in the cache_key the caller computed) + CACHE-12 (gateway timing contract — but the cache WRITE timing per CACHE-12 is the caller's responsibility, not the gateway's) + NFR-05 (CORS / rate-limit / sanitizer / JWT preserved on miss path) + NFR-06 (precheck synchronous lookup is <100ms p95 per NFR-02; the write itself is the caller's `EdgeRuntime.waitUntil` per Phase 37+).

Output: One modified shared helper, one modified test file. No edge handler changes — Phase 37+ will start passing the 4th arg.
</objective>
