Web Crypto SHA-256 body pattern (verified working in Deno + browser, source `src/pages/Upload.tsx:142-148`):
```
const bytes = new TextEncoder().encode(s);
const digest = await crypto.subtle.digest('SHA-256', bytes);
return Array.from(new Uint8Array(digest)).map(b => b.toString(16).padStart(2, '0')).join('');
```

Two-pass hashing algorithm (recommended by 29-RESEARCH.md):
  1. Hash user_id, feature, tier, variant (each individually) — each produces a 64-char hex string.
  2. For each sorted key `k` in `opts.inputs`, hash the string `${k}=${canonical(v)}` individually.
  3. Concatenate all component hashes with `|` separator and hash that string once more.
  Result is a single 64-char hex.

canonicalize(v):
  - null/undefined → ''
  - Array → JSON.stringify([...arr].sort())
  - string → v.normalize('NFC').trim()
  - else → String(v)
