<threat_model>
- **T-42-EXTRACT** — Worker writes to user-owned tables via service role. Mitigation: requireAuth({type:'internal'}) using timingSafeEqual on INTERNAL_JOB_SECRET; getServiceClient() bypasses RLS legitimately; structured logger emits per-write summary; failure isolated from caller (never propagates).
- **T-42-RLS** — A misconfigured worker could leak data across users. Mitigation: every insert explicitly sets user_id from the source analysis_results row (never trusts request body for user_id); UNIQUE(user_id, source_analysis_results_id) constraint catches accidental cross-user writes at DB layer.
</threat_model>
