<threat_model>
- **T-42-RLS** — Cross-user read/write of career_targets and new profiles education columns. Mitigation: career_targets ENABLE ROW LEVEL SECURITY + 3 explicit policies (career_targets_select_own / _insert_own / _update_own) all scoped via `auth.uid() = user_id`. Existing profiles RLS (`auth.uid() = id`) already covers the 5 new columns since RLS is table-wide, not column-scoped. Verification: DO $$ asserts policy count = 3 with predicates referencing auth.uid().
- **T-42-CUTOVER** — Legacy column DROP without backfill = data loss. Mitigation: backfill INSERT runs BEFORE DROP in the same transaction; ON CONFLICT (user_id) DO NOTHING preserves idempotency; pre/post row counts asserted in DO $$ verification block.
</threat_model>
