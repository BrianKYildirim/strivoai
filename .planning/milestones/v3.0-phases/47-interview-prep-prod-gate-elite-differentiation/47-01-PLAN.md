<objective>
Create the two reusable visual primitives every Wave 2 surface gate will consume: a small inline `<ComingSoonBadge />` tag and a full-page `<ComingSoon />` component. Both are intentionally flag-agnostic — they render unconditionally. Wave 2 surfaces decide *when* to render them based on `isInterviewPrepEnabled()`.

Purpose: One visual treatment for "Coming Soon" across every surface (nav, sidebar, dashboard tile, pricing bullets, history filter banner, route page). Centralizing the primitive prevents copy drift ("Coming Soon" vs "Coming back soon" vs "Soon!") and locks in the semantic-token approach so light/dark mode work out of the box.

Output: Two React components + their DOM tests, all using shadcn/Tailwind semantic tokens.
</objective>
