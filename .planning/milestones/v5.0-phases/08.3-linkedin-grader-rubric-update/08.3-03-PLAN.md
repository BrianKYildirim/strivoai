<threat_model>
Surface: `src/pages/LinkedInGrader.tsx` — client-side render of grader results (no auth surface; renders data the owner-scoped edge function returned). No secrets.

Threats addressed by this plan:
- **Rendering untrusted/legacy stored shapes (client robustness, ASVS V5 output handling):** stored `grading_data` can be any of four coexisting shapes (v3 loose, v4 11-section, v5 08.1 Education, new 08.3). A missing shape detector could crash the results view or mislabel maxes. Mitigation: add a new-shape detector while keeping all prior detectors; the render loop stays name/max-agnostic (`score/maxScore`, `rawScore/100`), so no shape is recomputed or backfilled. Never recompute a legacy record's stored total under the new rubric.

No new network/auth/secret surface. Block-on-high: do not remove any existing shape detector (would regress legacy rendering).
</threat_model>
