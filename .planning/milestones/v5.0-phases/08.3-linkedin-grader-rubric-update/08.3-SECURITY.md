## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Browser → grade-linkedin edge function | User-auth (JWT), usage-gated invocation | User-uploaded LinkedIn profile PDF text (user-controlled, untrusted) |
