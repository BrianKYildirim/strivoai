<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored analysis rows -> browser derivation | Historical or malformed jsonb rows can be absent, partial, stale, or legacy-shaped |
| tier access -> view depth | Frontend tier decides only display depth, not entitlement or backend state |
| derivation -> UI | Derived text must not claim unsupported personalized findings |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation |
|-----------|----------|-----------|----------|-------------|------------|
| T-07-01 | Information disclosure / integrity | source-backed insight rendering | MEDIUM | mitigate | D-05 source tags, safe accessors, and omission of unsupported bullets prevent unsupported personalized claims |
| T-07-02 | Tampering | malformed/historical jsonb rows | MEDIUM | mitigate | D-08 normalizers degrade per source and never throw into the render tree |
| T-07-03 | Spoofing / product integrity | tier depth display | LOW | mitigate | D-10/D-11 pure display-depth branch; no backend entitlement changes |
| T-07-04 | Repudiation | stale stored analysis dates | LOW | mitigate | D-06 staleness notes show source age/desync instead of silently presenting old data as current |
</threat_model>
