| Boundary | Description |
|----------|-------------|
| browser → status endpoint | A user must only read their own runs; ownership is RLS-enforced, not client-asserted |

| T-03-15 | Information Disclosure | Realtime cross-user broadcast | mitigate | owner-SELECT RLS scopes postgres_changes (verified on preview in 03-01, A3) |
