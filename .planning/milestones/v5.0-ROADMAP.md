## Overview

The journey moves from the most independent, lowest-risk foundation to the most externally-gated work. First, the one confirmed live outage and shared error contract are fixed centrally (CORS), then the auth/edge/RLS surface is audited and remediated (Security) â both regression-testable without product behavior change. Next the shared analysis-lifecycle substrate is shipped dormant: one persistent, idempotent, financially-safe state machine that wires the existing-but-unwired 4-arg Merit RPC and becomes the spine every feature adopts. Features then migrate in ascending blast radius â Recruiting Lens + LinkedIn (small, already broken, proves deterministic scoring), then Resume + Onboarding (highest traffic, dual path, fixes the hang), then Career Compass (most complex). Only after features store genuine analysis data does dashboard intelligence read it (no on-load AI). Paddle retirement comes last behind its verified expiration gate, ending in either clean removal or documented safe-prep. A final phase proves the whole milestone green across the extended baseline with real-account verification and the mandated evidence report. Every phase folds its new tests into `verify:baseline` â a green baseline only proves pre-existing behavior.
