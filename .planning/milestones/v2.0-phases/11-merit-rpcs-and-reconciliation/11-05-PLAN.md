<objective>
Add idempotent cleanup blocks to all 6 Phase 11 pgTAP test files so they can be re-run without hitting duplicate-key constraint violations. This closes UAT Gap 2 (blocker: all test files fail with `profiles_pkey` collision on second run) and confirms UAT Gap 1 (reconcile drift) is a test-environment contamination issue, not a code bug.

Purpose: The 6 test files use `BEGIN/ROLLBACK` for isolation, but `pg_prove` wraps each file in its own outer transaction creating nested savepoints. When a prior run crashes or times out, fixture rows from hardcoded UUIDs persist. On the next run, `INSERT INTO auth.users` and `INSERT INTO public.profiles` collide on the primary key. Adding idempotent `DELETE` statements for all fixture UUIDs at the start of each file (after `BEGIN`) ensures clean state regardless of prior run outcomes.

Output: 6 modified test files that pass on consecutive runs.
</objective>
