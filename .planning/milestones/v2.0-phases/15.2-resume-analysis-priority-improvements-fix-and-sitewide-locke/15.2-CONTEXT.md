# Phase 15.2: Resume Analysis Priority Improvements Fix & Sitewide Locked Section Design Unification - Context

**Gathered:** 2026-04-17
**Status:** Ready for planning

<domain>
## Phase Boundary

Fix the resume analysis priority improvements display for free-tier users and unify the locked section design across all feature pages with a new BlurredLockCard component.

**Workstream 1 — Resume Analysis Priority Improvements Fix:**

1. **Backend:** Update `applyTierShape` to keep exactly 1 `rewriteSuggestion` for free tier (currently stripped entirely per RES-02). The free prompt must generate at least 1 structured rewriteSuggestion.
2. **Frontend:** Free users see the same `PriorityCard` component as Pro/Elite for their 1 real improvement — with criteria name, original text, improved version, impact score. Below it, 4 locked placeholders rendered via the new `BlurredLockCard` component.

**Workstream 2 — Sitewide Locked Section Design Unification:**

1. **New** **`BlurredLockCard`** **component:** Reusable component that takes children (fake/placeholder content), renders them blurred with a lock overlay, hover-to-unlock animation, and click-through to `/pricing`.
2. **Results.tsx migration:** Replace all inline blur/lock patterns with `BlurredLockCard`. The 10 locked criteria and 4 locked improvements use this component.
3. **CareerCompass.tsx migration:** Replace all `LockedSection`/`LockedListItem` usage with `BlurredLockCard` using realistic placeholder content.
4. **RecruitingLens.tsx migration:** Replace all `LockedSection`/`LockedListItem` usage with `BlurredLockCard` using realistic placeholder content.
5. **LinkedInGrader.tsx free-tier:** Add partial results display for free users (currently blocked entirely by `ProFeatureGate`). Free users see specific unlocked sections with remaining content behind `BlurredLockCard`.
6. **Standard divider:** Consistent divider pattern between unlocked and locked content across all pages.
7. **Uniform upgrade CTA:** Same button style + text pattern across all pages below groups of locked items.

**Out of scope:**

* Changes to Pro/Elite display on any page (their content is fully unlocked)
* Merit deduction logic changes (Phase 13 contract unchanged)
* Changes to the async queue path
* New AI features or output schema changes beyond the 1-rewriteSuggestion addition for free
* InterviewPrep page (blocked by ProFeatureGate for free, no partial display needed)

</domain>

<decisions>
## Implementation Decisions

### Priority Improvements Fix (Resume Analysis)

* **D-01:** Update `applyTierShape` in `result-merger.ts` to keep exactly **1** **`rewriteSuggestion`** for free tier instead of stripping the entire array. The free prompt (`buildFreeConsolidatedPrompt`) must request at least 1 rewriteSuggestion with the full structured format: `{ title, originalText, improvedText, issues, impact, potentialScoreIncrease }`.
* **D-02:** Free users see their 1 real improvement rendered as a **`PriorityCard`** — identical component and data shape as Pro/Elite. No separate fallback path or plain div rendering.
* **D-03:** Below the real improvement, **4 locked placeholders** rendered via the new `BlurredLockCard` component with fake improvement content behind blur.

### BlurredLockCard Component

* **D-04:** Create a new **`BlurredLockCard`** component (`src/components/BlurredLockCard.tsx`) that accepts children (fake/placeholder content) and renders them with:
  * Blur overlay (`blur-sm opacity-50 pointer-events-none select-none`)
  * Lock icon centered over the blurred content (always visible)
  * On hover: lock icon **animates to "unlock" state**, text "Upgrade to unlock your full potential" appears below the lock icon
  * On hover off: lock icon **animates back to "locked" state**, text disappears
  * Clicking the lock icon or text navigates to `/pricing`
* **D-05:** This component **replaces** `LockedSection` and `LockedListItem` as the sitewide standard for locked content. Those Phase 14 components are deprecated but not deleted in this phase.

### Sitewide Design Consistency

* **D-06:** **Standard divider** between unlocked and locked content on every page: horizontal line with lock icon + "Upgrade to unlock N more \[items]" centered. Same pattern everywhere.
* **D-07:** **Uniform section-level upgrade CTA** below groups of locked items: same button style + text pattern `"Upgrade to Pro for full [feature name]"` with Crown icon. Consistent across all pages.
* **D-08:** **Results.tsx** — Replace all inline blur/lock patterns (improvements and criteria) with `BlurredLockCard`. The 10 locked criteria keep their current hardcoded fake scores/bullets rendered inside `BlurredLockCard` children.
* **D-09:** **CareerCompass.tsx** — Replace all `LockedSection`/`LockedListItem` usage with `BlurredLockCard` using realistic placeholder content as children.
* **D-10:** **RecruitingLens.tsx** — Replace all `LockedSection`/`LockedListItem` usage with `BlurredLockCard` using realistic placeholder content as children.

### LinkedIn Grader Free-Tier Display

* **D-11:** Remove the full `ProFeatureGate` block for free users. Free users now see **partial results** with locked content behind `BlurredLockCard`.
* **D-12:** **Free-tier visible content:**
  * Score card — fully visible
  * profileInsights ("What's Working for You") — fully unlocked
  * Key Strengths — fully visible
  * Next Best Action — fully visible
  * topFixes — **1 real entry only**, no locked placeholders after it
  * sectionBreakdown — **Profile Completeness section only** with 3 bullet points fully unlocked. All other sections (Headline & About, Experience, Skills & Endorsements) locked behind `BlurredLockCard` placeholders.
* **D-13:** **Backend changes:** Free prompt generates only visible fields (prompt + shaper defense-in-depth, same pattern as resume). `maxTokens = 3000`. Single Anthropic call — no parallelization for free tier.
* **D-14:** An `applyLinkedInTierShape` function (or update to existing shaper) strips any leaked fields for free tier.

### Claude's Discretion

* Exact animation implementation for the lock-to-unlock hover effect (Framer Motion, CSS transitions, or combination)
* Specific fake/placeholder text for BlurredLockCard children on each page
* Whether `BlurredLockCard` uses Framer Motion or CSS for the blur effect
* Whether the Profile Completeness section is identified by ID/key or by array index in sectionBreakdown
* Exact divider text variations per feature (e.g., "Upgrade to unlock 10 more criteria" vs "Upgrade to unlock 4 more improvements")
* Whether to delete or deprecate `LockedSection`/`LockedListItem` components

</decisions>

<specifics>
## Specific Ideas

* The BlurredLockCard hover animation should use Framer Motion's `whileHover` for the lock-to-unlock transition. The lock icon can morph from `Lock` to `Unlock` (both from lucide-react) with a smooth transition.
* "Upgrade to unlock your full potential" is the exact hover text specified by the user for the BlurredLockCard CTA.
* The LinkedIn Grader Profile Completeness section should be identified by a stable key/ID rather than array index to be robust against reordering.
* The free-tier LinkedIn Grader will need its own `buildFreeLinkedInPrompt()` (or equivalent) similar to how resume has `buildFreeConsolidatedPrompt()`.
* Each page's placeholder content for BlurredLockCard should look realistic — fake scores, fake bullet points, fake titles — behind blur so users can see there's substantial content they're missing.

</specifics>
