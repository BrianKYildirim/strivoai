<objective>
Switch the unlocked Free-tier criterion from C1 (Visual Clarity, 6% weight) to C6 (Achievement Orientation & Quantified Impact, 20% weight) across all backend files per D-06.

Purpose: C6 is the highest-weighted criterion (20%) and provides the most actionable value for Free users. The original Phase 15 implementation used C1 (index 0) which carries only 6% weight and is less impactful as a teaser for upgrades. This change affects FREE_TIER_SUFFIX (prompt constraint text), buildFreeConsolidatedPrompt (single-call JSON schema), and applyTierShape (defense-in-depth field stripping). Per D-06, the lookup must use `id === 'c6_achievement_orientation'` instead of array index 0 for robustness against criterion reordering.

Output: Modified resume-prompts.ts (FREE_TIER_SUFFIX + buildFreeConsolidatedPrompt) and result-merger.ts (applyTierShape).
