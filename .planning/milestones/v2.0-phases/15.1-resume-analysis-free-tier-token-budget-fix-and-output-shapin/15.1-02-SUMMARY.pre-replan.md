# Phase 15.1 Plan 02: Free Single-Call Routing Summary

Rewired analyze-resume/index.ts to route Free tier through a single consolidated Anthropic call (maxTokens=4000) instead of 3 parallel calls, cutting input token cost by ~67% while maintaining identical output shape via buildFreeConsolidatedPrompt + applyTierShape defense-in-depth.

## What Was Done

### Task 1: Constants, Quality Floor, and Boot-Time Assertions

Added foundational elements to `analyze-resume/index.ts`:

1. **Import**: Added `buildFreeConsolidatedPrompt` to the `resume-prompts.ts` import line
2. **FREE_SINGLE_CALL_MAX_TOKENS = 4000**: Local constant with GATE-09 compliance comment (4000/20000 = 20%, well under 50% ceiling)
3. **passesQualityFloor()**: Validator that rejects all-zero or all-identical criterion scores, runs on raw parsed JSON before reconcileScore/applyTierShape
4. **Boot-time assertions**: Two new checks after existing CALL_CONFIGS assertion:
   - `FREE_SINGLE_CALL_MAX_TOKENS <= TIER_MAX_TOKENS.free` (budget ceiling)
   - `FREE_SINGLE_CALL_MAX_TOKENS < 50% of TIER_MAX_TOKENS.elite` (GATE-09 ratio)

**Deviation (Rule 1 - Bug):** Moved constant definition before boot-time assertions. The plan placed assertions after the existing loop (line 60) but the constant after MERIT_COST (line 63). Since `const` is not hoisted in JS/TS, this would cause a ReferenceError at module load. Fixed by reordering: constant first, then all assertions.

**Commit:** 1637ed3

### Task 2: executeFreeAnalysis Helper and Merit Paths

1. **executeFreeAnalysis() helper**: Shared function that handles:
   - Single `invokeAnthropicText` call with `buildFreeConsolidatedPrompt`
   - JSON parse with `repairTruncatedJSON`
   - Quality floor check with single retry at temperature 0.4
   - `reconcileScore` -> `applyTierShape(result, 'free')` pipeline
   - Sets `_mergeSource = 'free-single'`
   - Throws Error with `.status` for caller-specific error handling

2. **Merit streaming path**: Free branch inserted after initial SSE chunk, before `executeParallelCalls`. Emits summary chunk, criteria chunk, complete event. Handles refunds via `refundMeritsForJob` on error.

3. **Merit non-streaming path**: Free branch inserted before `executeParallelCalls`. Wraps errors in `MeritRefundable` for gateway auto-refund.

**Commit:** 5b5b470

### Task 3: Legacy Paths and Fallback Updates

1. **Legacy streaming path**: Free branch with sendEvent error pattern and `record_ai_action` usage recording
2. **Legacy non-streaming path**: Free branch returning error Response directly with `record_ai_action` usage recording
3. **All 4 fallback paths updated (D-07)**:
   - Prompt selection: `buildFreeConsolidatedPrompt` for Free, `buildFallbackPrompt` for Pro/Elite
   - Token budget: `FREE_SINGLE_CALL_MAX_TOKENS` for Free, `TIER_MAX_TOKENS[resolvedTier]` for Pro/Elite

**Commit:** f2d13dd

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed const declaration ordering for boot-time assertion**
- **Found during:** Task 1
- **Issue:** Plan placed `FREE_SINGLE_CALL_MAX_TOKENS` constant after `MERIT_COST` (line 63) but boot-time assertions after the existing loop (line 60). `const` is not hoisted in JavaScript/TypeScript, so the assertion would reference the constant before it was defined, causing a ReferenceError at module load time.
- **Fix:** Reordered to define `FREE_SINGLE_CALL_MAX_TOKENS` and `MERIT_COST` first (after CALL_CONFIGS), then all boot-time assertions together afterward.
- **Files modified:** supabase/functions/analyze-resume/index.ts
- **Commit:** 1637ed3

## Decisions Made

1. **Constant ordering**: Placed `FREE_SINGLE_CALL_MAX_TOKENS` before `MERIT_COST` and all boot-time assertions to ensure correct declaration order.
2. **Error propagation**: `executeFreeAnalysis` throws plain `Error` with `.status`, not `MeritRefundable`. Each calling path wraps appropriately: merit paths convert to `MeritRefundable`, legacy paths return error `Response`.
3. **Fallback ternary pattern**: Used inline ternary (`resolvedTier === 'free' ? ... : ...`) for prompt and maxTokens selection in fallbacks, keeping changes minimal and localized.
