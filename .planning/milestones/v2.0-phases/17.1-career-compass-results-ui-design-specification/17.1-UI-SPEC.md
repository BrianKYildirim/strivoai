## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, badge-to-text spacing |
| sm | 8px | Compact element spacing, gap between list items in dense views |
| md | 16px | Default element spacing, card internal padding (compact), tab content gap |
| lg | 24px | Section padding within cards, gap between card sections |
| xl | 32px | Gap between major result cards |
| 2xl | 48px | Gap between top-level result sections (Career DNA to tabs) |
| 3xl | 64px | Not used in this phase |

Exceptions: Touch targets for tab triggers use min-height 44px for mobile accessibility.

## Layout Contract

### Results page layout (when `analysis` is not null):

```
Container: max-w-6xl mx-auto px-4 pt-6 pb-12
  |
  +-- Cached Results Banner (conditional: isFromCache)
  |     Layout: flex items-center justify-between, bg-muted/50 border rounded-lg px-4 py-3
  |
  +-- Career DNA Card (always visible, all tiers)
  |     Layout: Card p-8 text-center, border-color accent
  |     Content: Star icon (80x80 circle) + "Your Career DNA" heading + domain badge + DNA text
  |
  +-- Best-Fit Role Families Card (always visible)
  |     Layout: Card p-6
  |     Content: Ranked list (max 5), each row: flex justify-between with score bar
  |     Free tier: Shows received fields + LockedListItem for remaining up to 5
  |
  +-- Surprise Fits Card (conditional: surpriseFits exist)
  |     Layout: Card p-6 with dashed accent border
  |     Content: grid gap-3 sm:grid-cols-2
  |     Free tier: Shows received fits + LockedListItem for remaining up to 4
  |
  +-- Tabbed Results Section
        Layout: Tabs w-full
        Tab bar: grid w-full, 4 cols (Free/Pro) or 6 cols (Elite)
        |
        +-- Fields tab: Career field cards with match scores, salary, timeline, skills
        +-- Roles tab: Role cards with alignment scores, skill gaps, qualification steps
        +-- Readiness tab: Radial score + strengths/gaps grid + skill assessment table
        +-- Roadmap tab: Timeline with role-specific dropdown, border-left phase markers
        +-- Salary tab (Elite only): CompensationIntelligence component
        +-- Strategy tab (Elite only): SmartApplicationStrategy component
```

### Tier-conditional rendering rules:

| Element | Free | Pro | Elite |
|---------|------|-----|-------|
| Career DNA card | Full | Full | Full |
| Career Fields list | 1 entry + locked items | All entries | All entries |
| Surprise Fits | 1 entry + locked items | All entries | All entries |
| Role Readiness scorebox | Score only | Score + strengths/gaps + skill table | Score + strengths/gaps + skill table |
| Roadmap phases | First 2 phases + locked items | All 5 phases | All 5 phases |
| Compensation tab | Hidden | Hidden | Visible |
| Strategy tab | Hidden | Hidden | Visible |
| Role comparison button | Static badge (no click) | Interactive + dialog | Interactive + dialog |

## Interaction Contract

### Tab navigation:
- Default active tab: "fields"
- Tab switching: instant content swap, no transition animation
- Tab bar: sticky behavior not required (content is scrollable)
- Tab count adapts to tier: 4 tabs for Free/Pro, 6 tabs for Elite

### Role comparison dialog:
- Trigger: click on target role badge (Pro/Elite) or "Compare More" button
- Selection: checkbox-based multi-select, min 2, max 3 roles
- Search: real-time filtering of ~100 available roles
- Submit: "Compare Roles" button, disabled until 2+ selected
- Loading state: spinner card with selected role badges displayed
- Result: adds `multiRoleReadiness` to analysis, renders role tabs above score

### Roadmap role selector:
- Dropdown at top-right of roadmap card
- Default: "General Roadmap"
- Options: dynamically populated from `analysis.roleRoadmaps`
- Switching: instant content swap of roadmap steps

### Score radial chart:
- SVG circle, radius 70, stroke width 12
- Background circle: `text-muted/20`
- Progress circle: `#FF6B6B` stroke, dasharray calculated from score percentage
- Centered text: score percentage (text-4xl bold) + "Ready" label (text-xs)

### Refresh analysis:
- Visible only when `isFromCache === true`
- Button clears analysis state, returns to input form
- No confirmation dialog needed (non-destructive -- user can re-analyze)

## State Contract

### View states:

| State | Condition | What renders |
|-------|-----------|--------------|
| Loading (access check) | `checkingAccess === true` | Centered pulsing Compass icon + "Loading..." |
| Input form | `analysis === null && !loading` | Input form card with resume upload, LinkedIn PDF, LinkedIn URL |
| Analyzing | `loading === true` | UniversalAnalyzing overlay + inline progress steps |
| Results (fresh) | `analysis !== null && !isFromCache` | Full results view without cached banner |
| Results (cached) | `analysis !== null && isFromCache` | Full results view with cached banner + refresh button |
| Comparing roles | `comparingRoles === true` | Spinner card replacing readiness tab content |
| Role comparison results | `multiRoleReadiness.length > 0` | Role tab bar + active role detail |

### Animation contract:
- Results container: `animate-fade-in` class (0.4s ease-out, translateY 10px to 0)
- LockedSection: framer-motion opacity 0 to 1, 0.2s
- LockedSection lock icon: scale pulse [1, 1.05, 1] on 2s infinite loop (respects prefers-reduced-motion)
- Confetti: fires on successful analysis completion (canvas-confetti, particleCount: 100, spread: 70)
- Score ring: no entrance animation (static SVG dasharray)
- Progress bars: no entrance animation specified in current code

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Tab navigation | Radix Tabs handles keyboard arrow navigation natively |
| Score chart | SVG is decorative; score value is in visible text |
| Locked sections | `aria-hidden="true"` on blurred placeholder content |
| Locked section lock icon | `aria-hidden="true"` on decorative lock |
| Dialog focus trap | Radix Dialog handles focus trap natively |
| Reduced motion | LockedSection respects `useReducedMotion()` from framer-motion |
| Color contrast | Score colors (emerald/amber/red) used alongside text labels, not as sole indicator |
| Touch targets | Tab triggers use `py-3` (min 44px effective height) |

## Responsive Contract

| Breakpoint | Layout Change |
|------------|--------------|
| < 640px (mobile) | Career fields grid: single column. Surprise fits: single column. Strengths/gaps: stacked vertically. Skill table: horizontal scroll. Tab text may truncate. |
| >= 640px (sm) | Surprise fits: 2-column grid (`sm:grid-cols-2`) |
| >= 768px (md) | Strengths/gaps: 2-column grid (`md:grid-cols-2`). Career field detail: 2-column grid for salary/timeline. |
| >= 1024px (lg) | No additional changes |
| Max width | Container capped at `max-w-6xl` (72rem / 1152px) |
