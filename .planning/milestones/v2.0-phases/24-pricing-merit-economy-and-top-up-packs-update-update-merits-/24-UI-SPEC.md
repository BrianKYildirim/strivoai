# Phase 24 — UI Design Contract

> Visual and interaction contract for the retuned `/pricing` page + Merit Top-Up Pack surfaces + refreshed merit-balance header. Generated by gsd-ui-researcher. Inherits the Phase 20 contract for any surface NOT listed in `<scope>` below.

---

## Scope

**In-scope rebrand surfaces (opt into `theme-v2` wrapper class, per D-15/D-16):**
- `/pricing` page (3 subscription tiers + 4 top-up packs + Monthly/Annual toggle)
- Out-of-merits modal (triggered from feature pages when balance is insufficient)
- Header "+" quick-top-up trigger surface (the pop-out it launches — not the icon itself, which lives inside the existing TopBar)
- Dashboard "Running low?" card (shown when monthly-allocation balance <20%)
- Merit balance header readout (SC-10 format) — lives in `TopBar` but gets the JetBrains Mono numeric treatment without taking the full `theme-v2` wrapper

**Out-of-scope (preserve Phase 20 contract as-is):**
- `/shop` page (top-up flow now deep-links into `/pricing#packs` per D-24; `/shop` stays on current tokens until sitewide rebrand phase)
- `/settings/billing` (Phase 20 contract holds)
- Feature analyse pages (`MeritCostPreview` unchanged)
- `MeritBalancePopover` content rows (layout unchanged; only the header badge's numeric formatting shifts)
- All sidebar / nav / non-billing routes

## Typography

Phase-24 surfaces use a three-family stack. Sizes and weights conform to the 3–4 sizes × 2 weights rule.

| Role | Size | Weight | Line Height | Family | Usage |
|------|------|--------|-------------|--------|-------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | Inter Tight | Feature-list rows, pack descriptions, per-merit price, toggle labels |
| Label | 12px (text-xs) | 600 (semibold) | 1.5 | Inter Tight | Savings badge ("Save 17%"), "Best Value" badge, "Current Plan" badge, `+ 15 bonus` suffix in header |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 | Fraunces | Tier card plan name (Free / Pro / Elite), pack Merit count (e.g., "25 Merits") |
| Display | 28px (text-2xl) | 600 (semibold) | 1.2 | Fraunces | Page title ("Pricing"), Merit Top-Up Packs section heading, price amounts on tier cards |

**Numeric exception (SC-10):** Merit balance readout in the header and mono price digits use **JetBrains Mono 500 at 14px / 1.5** — mono is reserved for numerics only, not treated as a distinct typographic role.

Weights used: **400 (regular) + 600 (semibold)** — two weights only, plus the mono-500 numeric exception noted above.

## Interaction Contracts

### MeritBalanceHeaderV2 (TopBar, SC-10)

- **Layout**: Inline row — `<Gem className="h-4 w-4 text-[--accent-red]" />` + mono numerics + `<Progress>` bar + optional bonus suffix.
- **Normal state (no top-up balance)**: `"47 / 75 merits"` in JetBrains Mono 500 / 14px / `text-foreground`. The word `merits` is rendered in Inter Tight 400 / 12px / `text-muted-foreground` after a half-space.
- **With top-up balance (SC-10)**: `"47 / 75"` (mono 500 / 14px, foreground) + `"+ 15 bonus"` (mono 500 / 12px, `text-[--accent-red]`) separated by a single space.
- **Progress bar**: `<Progress value={monthly_balance / cap * 100} />` with track `bg-white/5` and fill `bg-[--accent-red]`. Width 80px. Height 4px. Placed between the numeric and the bonus suffix (or after the numeric when no suffix).
- **Low-balance trigger (≤20% of cap, per D-08 / SC-9b)**: Renders the `<HeaderTopUpTrigger />` `+` icon button directly to the right of the progress bar.
- **Click on numeric area**: Opens existing `MeritBalancePopover` (Phase 20 contract, unchanged).
- **Loading**: `<Skeleton className="h-5 w-28" />`.

### HeaderTopUpTrigger (+ icon, SC-9b)

- **Visibility rule**: `monthly_balance / MERITS_PER_MONTH[tier] < 0.2`. For Free (cap=10), shows at ≤2 monthly merits. Same rule all tiers per D-08.
- **Visual**: `<Button variant="ghost" size="icon">` with `<Plus className="h-4 w-4 text-[--accent-red]" />`. 24×24px hit target, padded to 32×32px for touch.
- **On click**: Navigate to `/pricing#packs` via React Router (`navigate('/pricing#packs')`). Browser scrolls to the pack section (CSS `scroll-margin-top: 96px` on `#packs`). Pack-25 card receives a 1.5-second `ring-2 ring-[--accent-red]` highlight pulse to orient the user (animation: `ring-flash` 1500ms ease-out).
- **aria-label**: `"Buy more merits"`.
- **Hidden when**: balance is ≥20% of cap, OR on `/pricing` itself (avoid redundant trigger).

### BillingIntervalToggleV2 (Monthly / Annual)

- **Component**: Radix Tabs with `TabsList` styled as a **boxy** segmented control (**NOT rounded-full** — this is the enforced rule per D-18 and the vitest lint scan).
- **Container**: `inline-flex h-10 items-center rounded-[--radius-boxy] bg-white/5 border border-white/10 p-1`.
- **Two triggers**: "Monthly" and "Annual", each `rounded-[--radius-boxy] px-6 py-2 text-sm font-medium`.
- **Active state**: `bg-[--accent-red] text-[--accent-red-foreground]`. Inactive: `text-muted-foreground hover:text-foreground`.
- **"Save 17%" badge**: Positioned above or inline-right of the "Annual" label. `text-xs font-semibold bg-emerald-500/15 text-emerald-500 border border-emerald-500/30 rounded-[--radius-boxy] px-2 py-0.5`.
- **Default**: Monthly (per SC-8).
- **Placement**: Centered above the 3-column tier grid, `mb-8` (32px gap to grid).

### TierCardV2

- **Layout**: Glass card — `bg-[--glass-bg] backdrop-blur-lg border border-[--glass-border] rounded-[--radius-boxy] p-6`. Vertical flex.
- **Plan name**: Fraunces 600 / 20px (Heading role). Free / Pro / Elite.
- **Price**: Fraunces 600 / 28px (Display role) for the amount. Period label in Inter Tight 400 / 14px `text-muted-foreground` ("/mo" or "/yr"). When Annual selected, show Annual total prominent + "(billed annually)" sub-label.
- **Crossed-out monthly equivalent (Annual)**: `text-sm text-muted-foreground line-through` — e.g., `"~~$8.99/mo~~ $7.50/mo"`.
- **Merit allowance line**: `text-sm font-semibold` with `<Gem className="h-4 w-4 text-[--accent-red]" />` inline. E.g., "75 Merits / month".
- **Feature list**: Inter Tight 400 / 14px. `<Check className="h-4 w-4 text-[--accent-red]" />` for included, `<X className="h-4 w-4 text-muted-foreground" />` for excluded.
- **Current plan highlight**: `border-[--accent-red]` 1px + `box-shadow: 0 0 24px var(--accent-red-glow)` + "Current Plan" badge (shadcn Badge, `variant="outline"` with red border) at top-right of card.
- **CTA button (boxy variant required)**:
  - Free unauth'd: "Sign Up Free" (outline boxy)
  - Free auth'd, is Free tier: "Current Plan" (outline boxy, disabled)
  - Pro, not current: "Get Pro" (primary boxy, `bg-[--accent-red]`)
  - Elite, not current: "Get Elite" (primary boxy, `bg-[--accent-red]`)
  - Current paid plan: "Current Plan" (outline boxy, disabled)
- **Grid**: `grid grid-cols-1 md:grid-cols-3 gap-6`. Stacks on mobile (SC-8).

### PackCardV2

- **Default layout**: Glass card (same base as TierCardV2), `rounded-[--radius-boxy] p-6`. Vertical flex. Center-aligned content.
- **Merit count**: Fraunces 600 / 28px (Display role) with `<Gem className="h-5 w-5 text-[--accent-red]" />` inline. E.g., "25 Merits".
- **Price**: JetBrains Mono 500 / 20px. E.g., `$9.99`.
- **Per-Merit price**: JetBrains Mono 500 / 12px `text-muted-foreground`. E.g., `$0.40 / Merit`.
- **Buy CTA**: Boxy primary Button, full-width, `bg-[--accent-red]`. Label: `"Buy {N} Merits"`.
- **`isBestValue=true` (pack_25 only)** — visual anchor treatment per SC-8:
  - Card `scale-105` on desktop (`md:scale-105`), normal scale on mobile
  - `border-[--accent-red]` 2px
  - Persistent ambient glow: `box-shadow: 0 0 32px var(--accent-red-glow)`
  - `"Best Value"` badge: top-right absolute position, `text-xs font-semibold bg-[--accent-red] text-[--accent-red-foreground] rounded-[--radius-boxy] px-3 py-1`
- **Grid**: `grid grid-cols-2 md:grid-cols-4 gap-4` — 2×2 on mobile per SC-8, 1×4 on md+.

### OutOfMeritsModalV2 (SC-9a)

- **Component**: shadcn Dialog, `max-w-md`.
- **Title**: Fraunces 600 / 20px — `"Out of Merits"`.
- **Body**: Inter Tight 400 / 14px `text-muted-foreground` — contextual message referencing the feature that triggered (see Copywriting Contract for exact copy).
- **Primary CTA (top)**: `TopUpCtaButton` — boxy primary full-width — `"Buy a top-up pack"`. On click: close modal, `navigate('/pricing#packs')`.
- **Secondary CTA (below)**: boxy **outline** full-width — `"Upgrade plan"`. On click: close modal, `navigate('/pricing')`.
- **Dismissal**: `Esc` / X button / overlay click all close the modal with no side effect.

### RunningLowCard (dashboard, SC-9c)

- **Trigger**: Visible on `/dashboard` only when `monthly_balance / cap < 0.2`.
- **Layout**: Glass card, 1-col card spanning full column width (or half on md+ depending on dashboard grid). `p-6`.
- **Heading**: Fraunces 600 / 20px — `"Running low?"`.
- **Body**: Inter Tight 400 / 14px `text-muted-foreground` — `"You have {N} merits left this cycle. A 25-pack adds 25 top-up merits that don't expire."`.
- **Mini pack display**: Inline `<Gem /> 25 merits · $9.99 · $0.40/Merit` in JetBrains Mono 500 / 14px.
- **Primary CTA**: `TopUpCtaButton` — boxy primary — `"Buy 25 Merits"`. On click: `navigate('/pricing#packs')`.
- **Secondary link**: Inter Tight 400 / 14px — `"Or upgrade your plan →"` — `text-[--accent-red] hover:underline`.

### StripePaymentElementModal (pack purchase path, D-23)

- **Trigger**: User clicks "Buy {N} Merits" on a `PackCardV2`. Frontend calls `create-payment-intent` edge function with `{ packId }`. Receives `clientSecret`.
- **Render**: shadcn Dialog `max-w-md`. Inside: Stripe `<Elements options={{ clientSecret }}>` → `<PaymentElement />` → boxy primary "Confirm purchase" submit button.
- **Title**: Fraunces 600 / 20px — `"Buy {N} Merits — ${price}"`.
- **Loading client secret**: `<Loader2 className="animate-spin" />` centered, `h-40`.
- **Success** (`stripe.confirmPayment` resolves ok): Close dialog → fire Sonner toast (copy in Copywriting Contract) → `invalidateQueries(['merit-balance'])`. No full reload; header live-updates via existing subscription.
- **Pending webhook** (confirm resolves but balance query hasn't re-fetched within 2s): Toast shows `"Processing…"` then updates when balance query lands.
- **Error**: Stripe error message surfaces inline within the Payment Element; dialog stays open so user can retry.

### Subscription purchase path (unchanged from Phase 20)

- Subscriptions still use Stripe **Checkout redirect** (not Payment Element). This is the Phase 20 contract and remains authoritative per D-23. The dual-path split is: subscription = Checkout redirect; top-up pack = embedded Payment Element.
