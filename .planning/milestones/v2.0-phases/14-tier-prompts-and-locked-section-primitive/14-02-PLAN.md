## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-02 | Tampering (prompt injection) | loader passes params through unchanged; sanitization remains caller's responsibility via existing `prompt-sanitizer.ts` | accept | The loader is a pure dispatcher — it does not touch user content. Existing sanitizer in `_shared/prompt-sanitizer.ts` already handles user-role messages (see CLAUDE.md Security Patterns). Document in JSDoc that callers must sanitize user-supplied params before invoking `loadPromptVariant`. |
| T-14-03 | Information disclosure (cost leak) | Free variant accidentally loaded with principles text would blow the $0.051/analysis Free ceiling | mitigate | Task 2 step 5 hard-codes `if (tier === 'free') return body;` and Task 3 test 5+6 assert the invariant. |
| T-14-04 | Elevation of Privilege (tier spoof) | Caller passes client-supplied tier | mitigate | Consumers (Phase 15+ edge functions) MUST read tier from `profiles.subscription_tier` server-side. Loader does not verify tier — that's the caller's job. Document in JSDoc header. |
