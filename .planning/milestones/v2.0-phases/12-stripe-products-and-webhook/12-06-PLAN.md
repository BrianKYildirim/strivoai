<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Stripe → webhook | Untrusted POST body; only SDK-verified events are honored |
| Webhook → DB | All writes go through SECURITY DEFINER RPCs or service-role UPDATE on profiles |
| Metadata → lookup | `session.metadata.user_id` is attacker-controllable if the session was created outside our flow; cross-check against stripe_customer_id as soft validation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Spoofing | webhook entry | mitigate | `stripe.webhooks.constructEventAsync` with `STRIPE_WEBHOOK_SECRET`; reject on any throw with 400 |
| T-12-02 | Tampering | duplicate webhook → double credit | mitigate | Insert-first on `stripe_webhook_events.event_id` UNIQUE; second layer via `merit_shop_purchases.stripe_payment_intent_id` UNIQUE inside credit_shop_merits RPC |
| T-12-03 | Tampering | concurrent upgrade + deduction race | mitigate | Phase 11 `grant_upgrade_diff` uses FOR UPDATE row lock |
| T-12-04 | Information Disclosure | wrong-user credit via metadata spoof | mitigate | metadata.user_id tried first, but only accepted if the corresponding profile row updates successfully; fallback chain runs after |
| T-12-05 | Denial of Service | Stripe retry storm from 5xx | mitigate | D-12 returns 200 on missing profile; only true internal errors return 5xx |
| T-12-06 | Elevation | hand-rolled HMAC bypass | accept→mitigate | SDK-only verification; no custom crypto paths in handler |
</threat_model>

           const prevTier = resolvedCurrentTier ?? 'free';
           if (sub.cancel_at_period_end === true) {
             await supabase.from("profiles").update({ pending_downgrade_tier: "free" }).eq("id", resolvedUserId);
             log.info("downgrade-scheduled", { eventId: event.id, from: prevTier, to: "free" });
           } else if (tierCompare(newTier, prevTier) > 0) {
             const { error: rpcErr } = await supabase.rpc("grant_upgrade_diff", {
               p_user_id: resolvedUserId,
               p_from_tier: prevTier,
               p_to_tier: newTier,
             });
             if (rpcErr) { log.error("upgrade-diff-rpc-failed", { eventId: event.id, code: (rpcErr as any).code }); return jsonResponse({ error: "rpc_failed" }, 500); }
             log.info("upgrade-diff-applied", { eventId: event.id, from: prevTier, to: newTier });
           } else if (tierCompare(newTier, prevTier) < 0) {
             // Downgrade — overwrite subscription_tier we already wrote back to prevTier, then set pending.
             await supabase.from("profiles").update({
               subscription_tier: prevTier,
               pending_downgrade_tier: newTier,
             }).eq("id", resolvedUserId);
             log.info("downgrade-scheduled", { eventId: event.id, from: prevTier, to: newTier });
           }
         }
       } catch (err) {
         log.error("router-failed", { eventId: event.id, type: event.type, message: err instanceof Error ? err.message : "unknown" });
         return jsonResponse({ error: "router_failed" }, 500);
       }
