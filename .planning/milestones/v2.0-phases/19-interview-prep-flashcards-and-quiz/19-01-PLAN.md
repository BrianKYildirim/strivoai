**Table 1: `interview_quizzes`**
```sql
CREATE TABLE IF NOT EXISTS public.interview_quizzes (
  id                    uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id               uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  mode                  text NOT NULL CHECK (mode IN ('flashcard', 'quiz')),
  tier                  text NOT NULL CHECK (tier IN ('pro', 'elite')),
  job_description       text NOT NULL,
  job_title             text,
  company               text,
  resume_id             uuid REFERENCES public.resumes(id),
  overall_score         integer,
  evaluated_at          timestamptz,
  merit_transaction_id  text,
  created_at            timestamptz NOT NULL DEFAULT now()
);
```
- `mode` distinguishes Pro flashcard sessions from Elite quiz sessions (per D-04).
- `overall_score` is NULL until `interview-prep-evaluate` writes it back (Elite only).
- `evaluated_at` is NULL until evaluation completes.
- `merit_transaction_id` links to the `merit_transactions` row (for refund tracing).
- `resume_id` references the resume used for generation.

**Table 2: `interview_quiz_answers`**
```sql
CREATE TABLE IF NOT EXISTS public.interview_quiz_answers (
  id                  uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  quiz_id             uuid NOT NULL REFERENCES public.interview_quizzes(id) ON DELETE CASCADE,
  question_order      integer NOT NULL,
  question_text       text NOT NULL,
  competency          text,
  star_answer         jsonb,
  user_answer         text,
  score               integer,
  scoring_breakdown   jsonb,
  suggestions         text[],
  created_at          timestamptz NOT NULL DEFAULT now()
);
```
- For Pro flashcards: `star_answer` is populated on generation (contains `{ situation, task, action, result }`), `user_answer` stays NULL.
- For Elite quiz: `question_text` + `competency` populated on generation, `user_answer` + `score` + `scoring_breakdown` + `suggestions` populated on evaluation.
- `scoring_breakdown` shape: `{ situation_score, task_score, action_score, result_score, feedback }`.

**Table 3: `interview_streaks`**
```sql
CREATE TABLE IF NOT EXISTS public.interview_streaks (
  user_id         uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  current_streak  integer NOT NULL DEFAULT 0,
  last_quiz_at    timestamptz,
  last_quiz_date  date,
  updated_at      timestamptz NOT NULL DEFAULT now()
);
```
- One row per user (per D-10, D-11).
- `last_quiz_at` for rolling-hour cold/expire calculation.
- `last_quiz_date` for "first quiz of the day" streak increment check.

**Indexes:**
```sql
CREATE INDEX idx_interview_quizzes_user_created ON interview_quizzes(user_id, created_at DESC);
CREATE INDEX idx_interview_quiz_answers_quiz ON interview_quiz_answers(quiz_id, question_order);
```

**RLS (service-role-only writes, user reads own):**
- Enable RLS on all 3 tables.
- `interview_quizzes`: SELECT policy `USING (auth.uid() = user_id)`.
- `interview_quiz_answers`: SELECT policy `USING (quiz_id IN (SELECT id FROM interview_quizzes WHERE user_id = auth.uid()))`.
- `interview_streaks`: SELECT policy `USING (auth.uid() = user_id)`.
- NO INSERT/UPDATE/DELETE policies for users. All writes go through service-role client in edge functions.
