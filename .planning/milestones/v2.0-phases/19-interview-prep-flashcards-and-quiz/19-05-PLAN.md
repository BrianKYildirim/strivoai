  - List of all questions with truncated answers (first 80 chars + "..." if longer).
  - Each item: Card with question number, question text (truncated), answer preview.
  - "Submit All Answers" primary CTA button (full width).
  - "Go Back & Edit" outline button.

- **Submitting view** (when `submitting`):
  - Inline card with `Loader2` spinner + "Evaluating your answers..." text.
  - "This takes about 10 seconds" duration indicator.

- **handleSubmitAll** function:
  CRITICAL: Pass `clientAnswers` alongside the API response so the parent (InterviewPrep.tsx) can provide user answer text to the results screen. The evaluate API response does NOT include original answer text -- answers only live in InterviewQuiz's local state.
  ```typescript
  const handleSubmitAll = async () => {
    setSubmitting(true);
    try {
      const { data, error } = await invokeWithTimeout('interview-prep-evaluate', {
        body: {
          quiz_id: quizId,
          answers: questions.map(q => ({
            question_id: q.id,
            answer_text: answers[q.id] || '',
          })),
        },
      }, 120000);

      if (error) {
        const errMsg = data && typeof data === 'object' && 'message' in data
          ? (data as any).message
          : 'Evaluation failed. Please try again.';
        onError(errMsg);
        return;
      }
      // Attach client-side answers to results so parent can pass to QuizResultsCard
      onResults({ ...data, clientAnswers: answers });
    } catch (err) {
      onError((err as Error).message || 'Something went wrong.');
    } finally {
      setSubmitting(false);
    }
  };
  ```
