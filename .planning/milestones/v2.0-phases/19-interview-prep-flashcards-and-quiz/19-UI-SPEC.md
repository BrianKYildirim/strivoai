# Phase 19 — UI Design Contract

> Visual and interaction contract for the Interview Prep Flashcards & Quiz frontend. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

***

## Design System

| Property          | Value                                          |
| ----------------- | ---------------------------------------------- |
| Tool              | shadcn/ui (default style)                      |
| Preset            | slate base, CSS variables, `--radius: 0.75rem` |
| Component library | Radix UI primitives via shadcn                 |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage                                                            |
| ----- | ----- | ---------------------------------------------------------------- |
| xs    | 4px   | Icon gaps, inline badge padding, character counter offset        |
| sm    | 8px   | Compact element spacing, gap between badges, card inner gaps     |
| md    | 16px  | Default element spacing, card padding on mobile, textarea margin |
| lg    | 24px  | Section padding, card content padding on desktop                 |
| xl    | 32px  | Layout gaps between major sections (input form to results)       |
| 2xl   | 48px  | Major section breaks, page top/bottom padding                    |
| 3xl   | 64px  | Not used in this phase                                           |

Exceptions: 48px minimum touch target for quiz "Submit Answer", "Next Question", and "Previous" buttons on mobile. This exceeds the WCAG 2.1 44px minimum while remaining grid-aligned to multiples of 4.

## Typography

| Role    | Size | Weight         | Line Height | Usage                                                                                                                                                              |
| ------- | ---- | -------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Body    | 14px | 400 (regular)  | 1.5         | Card body text, flashcard answers, quiz answer text, descriptions, section labels, character counters, "STAR" category tags, streak counter text, "1/3 used today" |
| Heading | 20px | 600 (semibold) | 1.2         | Card titles (flashcard question, quiz question), section headers ("Your Flashcards", "Quiz Results"), page title "Interview Prep", overall readiness score number  |

Two weights only: 400 (regular) for all body-level text including labels and counters, 600 (semibold) for all heading-level text including display-size elements. Display-size text (28px page title, readiness score) uses the same 600 weight at a larger size -- it is not a separate weight tier.

Font size reference (all use one of the two weights above):

| Context                                                                            | Size | Weight |
| ---------------------------------------------------------------------------------- | ---- | ------ |
| Body text, flashcard answers, quiz answers, descriptions                           | 14px | 400    |
| Section labels, character counters, STAR category tags, streak text, daily counter | 12px | 400    |
| Card titles, section headers, question text                                        | 20px | 600    |
| Page title "Interview Prep", readiness score number                                | 28px | 600    |

## Page States & Interaction Flows

### State Machine

```
[loading] --> [free-gate] (if Free tier)
[loading] --> [input-form] (if Pro or Elite)
[input-form] --> [generating] (on "Generate Flashcards" / "Start Quiz")
[generating] --> [flashcard-results] (Pro: 3 flashcards returned)
[generating] --> [quiz-active] (Elite: questions returned)
[generating] --> [error] (AI failure or no resume)
[quiz-active] --> [quiz-submitting] (all answers submitted)
[quiz-submitting] --> [quiz-results] (evaluation returned)
[quiz-submitting] --> [error] (evaluation failure)
[flashcard-results] --> [input-form] (on "Generate New Flashcards")
[quiz-results] --> [input-form] (on "Start New Quiz")
[error] --> [input-form] (on "Try Again")
```

### 1. Loading State

* Full-page skeleton matching the input form layout
* Duration: 400ms (consistent with existing InterviewPrep.tsx pattern)

### 2. Free Tier Gate (IPC-01)

* `ProFeatureGate` with:
  * `featureName`: "Interview Prep"
  * `featureIcon`: `<MessageSquare className="h-8 w-8" />`
  * `featureColor`: `"hsl(var(--primary))"`
  * `description`: "Master your next interview with AI-powered flashcards and interactive quizzes tailored to your resume and target role."
  * `benefits`: \["STAR-framework flashcards from your resume", "Interactive quiz with per-answer scoring", "Streak tracking to build consistency", "Personalized to your target job description"]

### 3. Input Form (Pro & Elite)

* **Layout**: Single column, max-width 640px, centered
* **Primary visual anchor**: The job description textarea is the focal point of this state. It is the largest interactive element and the only required field. Visual hierarchy flows: page title (28px, 600 weight) -> resume status banner -> JD textarea (focal point) -> optional fields -> streak display -> CTA button.
* **Resume status banner**: Card at top showing "Using: {filename}" with CheckCircle2 icon (green) or "No resume on file" with AlertCircle + "Analyze My Resume" CTA linking to `/onboarding`
* **Job description textarea**: Required, maxLength 3000, min-height 200px, character counter bottom-right. This is the primary visual anchor of the input form -- it receives the most vertical space and draws the user's eye as the first action they must take.
* **Job title input**: Optional, single line
* **Company input**: Optional, single line
* **Job title + company**: Side by side on sm+ breakpoint, stacked on mobile
* **Streak display**: Positioned above the CTA button (only visible for Elite users with existing streak data)
* **CTA button**: Full width
  * Pro label: "Generate Flashcards"
  * Elite label: "Start Quiz"
  * Disabled when JD is empty
  * Icon: `Sparkles` (14px, left of text)

### 4. Generating State

* `UniversalAnalyzing` overlay with:
  * Pro title: "Generating Your Flashcards"
  * Elite title: "Building Your Quiz"
  * subtitle: "This usually takes 15-20 seconds"
  * icon: `<MessageSquare className="w-8 h-8 text-primary" />`
  * steps:
    * `{ id: "resume", label: "Reading your resume", icon: <FileText /> }`
    * `{ id: "jd", label: "Analyzing job description", icon: <Sparkles /> }`
    * Pro: `{ id: "flashcards", label: "Building STAR flashcards", icon: <Brain /> }`
    * Elite: `{ id: "quiz", label: "Crafting quiz questions", icon: <Brain /> }`
  * stepDuration: 5000

### 5. Pro Flashcard Results

* **Header**: "Your STAR Flashcards" (heading) + "3 flashcards tailored to your resume and target role" (body)
* **Layout**: Vertical stack of 3 FlashcardCard components, 16px gap
* **Each FlashcardCard**:
  * Card with `border border-border bg-card` (consistent with existing pattern)
  * Top: Question in heading weight (600), prefixed with "Q{n}." and Badge showing category
  * Body: STAR answer with 4 labeled sections:
    * Each section: Semibold label ("Situation:", "Task:", "Action:", "Result:") followed by body text
    * Labels use `text-primary` color
    * Sections separated by 8px vertical gap
  * Copy button: ghost variant, icon-only (`Copy` icon from lucide-react), positioned top-right of card. Renders with `aria-label="Copy answer"`. Wrapped in a `Tooltip` that shows "Copy answer" on hover/focus. On click, copies the full STAR answer text to clipboard and briefly shows a `Check` icon for 2 seconds before reverting to `Copy`.
* **Bottom action**: "Generate New Flashcards" button (outline variant) with RefreshCw icon

### 6. Elite Quiz Active

* **Layout**: Single question at a time, centered, max-width 640px
* **QuizProgressIndicator**: Horizontal dot row at top
  * Each dot: 8px circle
  * Current question: accent fill
  * Answered questions: accent fill at 40% opacity
  * Unanswered questions: muted fill
  * 8px gap between dots
* **QuizQuestionCard**:
  * Card with `border border-border bg-card`, padding 24px
  * Top: "Question {n} of {total}" label (12px, regular weight, muted-foreground)
  * Question text: heading weight (600), 20px, `text-foreground`
  * Textarea: 500-char max, min-height 160px, resize-y
  * Character counter: bottom-right, 12px, muted-foreground; turns `text-destructive` at 500/500
  * Format: "{current}/{max}" (e.g. "327/500")
* **Navigation**: Two buttons below the card
  * "Previous" (outline, left-aligned) -- hidden on question 1
  * "Next Question" (default, right-aligned) -- changes to "Review & Submit" on last question
  * Both 48px min-height on mobile (grid-aligned, exceeds WCAG 44px minimum)
* **Review state** (after clicking "Review & Submit" on last question):
  * Shows all questions with truncated answers (first 80 chars + "...")
  * "Submit All Answers" primary CTA button
  * "Go Back & Edit" outline button

### 7. Quiz Submitting State

* Inline card with `Loader2` spinner + "Evaluating your answers..." text
* No full-page overlay (user already invested time; show inline feedback)
* Duration indicator: "This takes about 10 seconds"

### 8. Elite Quiz Results

* **Overall Readiness Score**: `ReadinessScoreRing` component
  * Animated SVG circle (same pattern as existing InterviewPrep results: 120x120 viewBox, r=52, strokeWidth=8)
  * Score number centered inside ring (28px, 600 weight)
  * Score label Badge below (e.g. "Strong", "Ready", "Needs Work")
  * Summary paragraph (body text)
* **Per-Question Breakdown**: Vertical stack of `QuizResultsCard` components
  * Card header: "Question {n}" + score badge (colored by score range)
  * "Your answer" section: user's answer in muted body text, bordered-left with 2px accent border
  * "STAR Breakdown" section: 4 horizontal mini-bars (Situation / Task / Action / Result)
    * Each bar: label (12px) + score out of 10 + filled progress bar
    * Bar colors follow the score-color scale
  * "Suggestions" section: Bulleted list of improvement suggestions (body text, muted-foreground)
* **Bottom actions**:
  * "Start New Quiz" primary button with RefreshCw icon
  * Streak update confirmation: "Streak updated! {N} day streak" inline text with Flame icon (shown only when streak incremented)

### 9. Error State

* Card with `border-destructive/50` border
* AlertCircle icon (destructive color)
* Heading: Varies by error type
  * No resume: "Upload a Resume First"
  * Body: "Analyze your resume before generating interview prep. Your resume powers the personalized questions."
  * CTA: "Analyze My Resume" linking to `/onboarding`
  * Daily cap exceeded: "Daily Limit Reached"
  * Body: "You've used all 3 quiz sessions for today. Come back tomorrow to continue your streak!"
  * CTA: none (informational only), show "Resets at midnight UTC"
  * AI failure: "Something Went Wrong"
  * Body: "We couldn't generate your {flashcards/quiz}. Your Merits have been refunded."
  * CTA: "Try Again" (outline)

## Streak Display Specification (UX-10)

### Visual States

**Active (quiz within last 24h)**:

* Flame icon (lucide `Flame`, 20px) in accent color with subtle `animate-bounce-subtle` animation
* "{N}-day streak" text in `text-foreground`, 14px semibold (600 weight)
* Daily counter "{used}/3 quizzes today" in muted-foreground, 12px
* Background: rounded-lg card with accent/15 background tint

**Cold (24-48h since last quiz)**:

* Flame icon in `text-muted-foreground` (no animation)
* "{N}-day streak" text in `text-muted-foreground`, 14px semibold (600 weight)
* "Quiz today to keep it!" in amber-500, 12px
* Background: rounded-lg card with muted background

**Expired (> 48h since last quiz)**:

* Flame icon in `text-muted-foreground/40` with a small "X" overlay or strikethrough effect
* "Streak lost" text in `text-muted-foreground`, 14px regular (400 weight)
* "Start New Streak" CTA as text link in accent color
* Daily counter still shown: "0/3 quizzes today"

**No streak history (first-time user)**:

* Flame icon in muted, no animation
* "Start your streak!" text in `text-muted-foreground`, 14px
* "Complete a quiz to begin" in 12px muted-foreground

### Placement

* On `InterviewPrep.tsx` page: Above the CTA button in the input form (Elite users only)
* On dashboard: As a standalone `StreakDisplay` component (positioned by Phase 20 if not already placed)

## Animation & Motion

| Element                  | Animation                                     | Duration             | Easing      |
| ------------------------ | --------------------------------------------- | -------------------- | ----------- |
| Page entrance            | Fade-in + translateY(20px to 0)               | 400ms                | ease-out    |
| Flashcard cards          | Staggered fade-in (100ms delay between cards) | 300ms each           | ease-out    |
| Quiz question transition | Slide from right (translateX(100% to 0))      | 300ms                | ease-out    |
| Quiz question exit       | Slide to left (translateX(0 to -100%))        | 300ms                | ease-out    |
| Readiness score ring     | strokeDashoffset animation from full to score | 1200ms               | ease-out    |
| Score number             | Scale from 0.5 to 1 + fade-in                 | spring (delay 400ms) | spring      |
| STAR progress bars       | Width from 0 to score%                        | 800ms                | ease-out    |
| Streak flame (active)    | bounce-subtle (existing keyframe)             | 2s infinite          | ease-in-out |
| Submit button loading    | Loader2 spin                                  | continuous           | linear      |
| Error card               | scale-in (0.95 to 1) + fade-in                | 300ms                | ease-out    |

All animations respect `useReducedMotion` from Framer Motion. When reduced motion is preferred, replace all motion animations with instant opacity transitions.

## Accessibility

| Requirement         | Implementation                                                                                                                    |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Focus management    | After quiz question transition, focus moves to the new textarea                                                                   |
| Keyboard navigation | Tab through question navigation; Enter submits current answer and advances                                                        |
| Screen reader       | `aria-live="polite"` on character counter; `role="progressbar"` on quiz progress and score rings                                  |
| Color contrast      | All text meets WCAG 2.1 AA (4.5:1 for body, 3:1 for large text). Score colors used alongside text labels, never alone             |
| Reduced motion      | All framer-motion animations check `useReducedMotion`; fallback to opacity-only transitions                                       |
| Touch targets       | All buttons minimum 48px height on mobile (grid-aligned, exceeds WCAG 44px minimum); quiz navigation buttons full-width on mobile |
| Live regions        | Streak state changes and score reveals announced via `aria-live="polite"`                                                         |
| Copy button         | `aria-label="Copy answer"` on FlashcardCard copy button; tooltip shown on hover/focus as visible label mechanism                  |
