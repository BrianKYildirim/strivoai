**2. Add the `applyTierShape` function before the `mergeAndValidateResults` export (around line 220):**

```typescript
/**
 * Tier-aware output shaper (Phase 15 — D-11/D-12).
 * Strips fields not in the per-tier whitelist, caps priorityImprovements,
 * and strips feedback detail from C2-C11 for Free tier.
 *
 * This is the SINGLE exit point for all tier shaping — called inside
 * mergeAndValidateResults and also directly by fallback paths.
 * Mutates the merged object in place for zero-copy efficiency.
 *
 * @param merged - The merged grading_data object (mutated in place)
 * @param tier - The server-resolved tier ('free' | 'pro' | 'elite')
 */
export function applyTierShape(
  merged: Record<string, unknown>,
  tier: 'free' | 'pro' | 'elite',
): void {
  const whitelist = tier === 'elite' ? ELITE_ALLOWED_FIELDS
    : tier === 'pro' ? PRO_ALLOWED_FIELDS
    : FREE_ALLOWED_FIELDS;

  // Strip keys not in whitelist
  for (const key of Object.keys(merged)) {
    if (!whitelist.has(key)) {
      delete merged[key];
    }
  }

  // Cap priorityImprovements per tier (D-13: relocated from handler)
  // Spec §4.1: free=1, pro=5, elite=7
  const IMPROVEMENT_CAPS: Record<string, number> = { free: 1, pro: 5, elite: 7 };
  if (Array.isArray(merged.priorityImprovements)) {
    merged.priorityImprovements = (merged.priorityImprovements as unknown[]).slice(0, IMPROVEMENT_CAPS[tier]);
  }

  // Free tier: strip feedback from C2-C11 (D-14)
  // C1 (index 0) keeps full feedback {observation, impact, fix}.
  // C2-C11 (indices 1-10) keep only {id, label, weight, score} for rendering.
  if (tier === 'free' && Array.isArray(merged.criterionFeedback)) {
    merged.criterionFeedback = (merged.criterionFeedback as Record<string, unknown>[]).map((c, i) => {
      if (i === 0) return c; // C1 Visual Clarity: keep full feedback
      return { id: c.id, label: c.label, weight: c.weight, score: c.score };
    });
  }
}
```

| T-15-02 | Information Disclosure | criterionFeedback C2-C11 for Free | mitigate | applyTierShape explicitly maps C2-C11 entries to {id, label, weight, score} only, stripping feedback object regardless of what model returned. |
| T-15-03 | Elevation of Privilege | tier parameter to mergeAndValidateResults | accept | The tier parameter comes from the handler which reads it server-side. The merger does not validate tier authenticity -- that is the handler's responsibility (addressed in Plan 03). |
