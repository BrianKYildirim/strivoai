## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(var(--background))` -- dark: `hsl(0 0% 0%)`, light: `hsl(0 0% 100%)` | Page backgrounds, layout surfaces |
| Secondary (30%) | `hsl(var(--card))` -- dark: `hsl(0 0% 5%)`, light: `hsl(0 0% 98%)` | Pricing cards, shop pack cards, billing card, popover background, purchase history table |
| Accent (10%) | `hsl(var(--primary))` -- dark: `hsl(357 100% 68%)`, light: `hsl(357 100% 55%)` | See reserved-for list below |
| Destructive | `hsl(var(--destructive))` -- dark: `hsl(0 84.2% 60.2%)`, light: `hsl(0 84.2% 50%)` | Zero-balance badge text, "Out of Merits" text, cancel subscription link |
| Warning (amber) | `amber-500` (`#f59e0b`) | Low-balance badge tint, low-balance warning banner border/icon, cost preview amber state |
| Success (green) | `emerald-500` (`#10b981`) | Savings badges on yearly pricing, "Most Popular" badge background, successful purchase confirmation |

Accent reserved for:
- "Get Pro" / "Get Elite" CTA buttons on pricing cards (bg-primary)
- "Buy" CTA buttons on shop pack cards (bg-primary)
- Merit balance badge icon and count text in TopBar
- Current plan highlighted border on pricing cards (border-primary)
- "Change Plan" link on billing page
- Active state of monthly/yearly pill toggle

## Interaction Contracts

### MeritBalanceBadge (TopBar)

- **Idle state**: Gem icon (Lucide `Gem`) + total Merit count as text, `text-sm font-semibold`. Colors: icon and count use `text-primary`.
- **Low-balance state**: When total < 4 Merits, badge background shifts to `bg-amber-500/10`, icon and count use `text-amber-500`, border `border-amber-500/30`.
- **Zero-balance state**: Badge background `bg-destructive/10`, icon and count use `text-destructive`, border `border-destructive/30`.
- **Click**: Opens `MeritBalancePopover` anchored to the badge (Radix Popover, align="end", sideOffset=8).
- **Loading**: Skeleton placeholder `w-12 h-6 rounded-full bg-muted animate-pulse`.

### MeritBalancePopover

- **Width**: 280px (w-70).
- **Content**:
  - Row 1: "Subscription Merits" label + subscription_balance value, right-aligned.
  - Row 2: "Shop Merits" label + shop_balance value, right-aligned.
  - Separator (shadcn Separator).
  - Row 3: "Total" label + total value in `font-semibold`, right-aligned.
  - Row 4 (Pro/Elite only): "Resets [date]" in `text-xs text-muted-foreground`.
  - Low-balance warning (if total < 4): Amber callout box with `AlertTriangle` icon + "Running low on Merits" text.
  - Two links: "Buy Merits" (Link to `/shop`) and "Change Plan" (Link to `/pricing`), styled as `text-sm text-primary hover:underline`, separated by a centered dot.

### MeritCostPreview (Feature Pages)

- **Placement**: Directly above the Analyze/Submit button, left-aligned with button width.
- **Normal state**: `text-sm text-muted-foreground`. Copy: "Costs {X} Merits -- {Y} remaining".
- **Low-balance state** (total < 2x feature cost): `text-sm text-amber-500`. Copy: "Costs {X} Merits -- {Y} remaining" with `AlertTriangle` icon (h-4 w-4) inline before text.
- **Zero-balance state**: `text-sm text-destructive`. Copy: "Out of Merits". Analyze button disabled (`opacity-50 pointer-events-none`). Below the cost line, two inline CTAs: "[Buy Merits](/shop)" and "[Upgrade Plan](/pricing)" as `text-sm text-primary hover:underline`, separated by a centered dot.
- **Insufficient for feature** (can afford something but not this feature): Same as zero-balance visual treatment. Copy: "Not enough Merits ({Y} remaining, costs {X})".

### BillingIntervalToggle (Pricing Page)

- **Component**: Radix Tabs (shadcn `tabs.tsx`) with `TabsList` styled as a pill: `inline-flex h-10 items-center rounded-full bg-muted p-1`.
- **Two triggers**: "Monthly" and "Yearly" as `TabsTrigger` with `rounded-full px-6`.
- **Active state**: `bg-background text-foreground shadow-sm` (shadcn default active tab).
- **Placement**: Centered above the 3-column pricing grid, `mb-8` (32px gap to cards).

### PricingCard

- **Layout**: shadcn Card, full height, vertical flex. Header (plan name + price), feature list, CTA button at bottom.
- **Plan name**: `text-xl font-semibold` (Heading role).
- **Price**: `text-2xl font-semibold` (Display role) for the amount. Period label `text-sm text-muted-foreground` ("/mo" or "/yr").
- **Yearly crossed-out price**: `text-sm text-muted-foreground line-through` showing the monthly equivalent. E.g., "~~$8.99/mo~~ $7.50/mo".
- **Savings badge**: `text-xs font-semibold bg-emerald-500/15 text-emerald-500 border border-emerald-500/30 rounded-full px-2 py-1`. Copy: "Save $17.98" or "Save $33.89".
- **Merit allowance line**: `text-sm font-semibold`. E.g., "75 Merits/month" with Gem icon inline.
- **Feature list**: Check icons (`Check` lucide, `h-4 w-4 text-primary`) for included features. X icons (`X` lucide, `h-4 w-4 text-muted-foreground`) for excluded features.
- **Current plan highlight**: `border-2 border-primary` on the Card. "Current Plan" badge (shadcn Badge, variant="default") positioned at the top-right corner of the card or above the plan name.
- **CTA button**:
  - Free card, unauthenticated: "Sign Up Free" (Button variant="outline").
  - Free card, authenticated Free user: "Current Plan" (Button disabled, variant="outline").
  - Pro plan, not current: "Get Pro" (Button variant="default" with bg-primary).
  - Elite plan, not current: "Get Elite" (Button variant="default" with bg-primary).
  - Current paid plan: "Current Plan" (Button disabled, variant="outline").
- **Grid**: 3 columns on desktop (`grid grid-cols-1 md:grid-cols-3 gap-6`), stacked on mobile.

### ShopPackCard

- **Layout**: shadcn Card, vertical. Gem count at top (large), price, per-Merit price, Buy button.
- **Gem count**: `text-2xl font-semibold` (Display role) with Gem icon inline.
- **Price**: `text-xl font-semibold` (Heading role).
- **Per-Merit price**: `text-xs text-muted-foreground`. E.g., "$0.40/Merit".
- **"Most Popular" badge** (25-pack only): Positioned at top-right of card. `text-xs font-semibold bg-emerald-500 text-white rounded-full px-3 py-1`. Card gets `border-2 border-emerald-500` and `ring-2 ring-emerald-500/20`.
- **Buy button**: Button variant="default" (bg-primary), full width. Label: "Buy {N} Merits".
- **Grid**: `grid grid-cols-2 md:grid-cols-4 gap-4`.

### UpgradeComparisonBanner

- **Trigger**: Appears below a specific pack card based on user tier and pack size.
- **Free user viewing 25-pack**: Callout with `bg-primary/5 border border-primary/20 rounded-lg p-4`. Copy: "Pro gives you 75 Merits/month for $8.99 -- 3x more for less". CTA: "[View Pro](/pricing)" as `text-sm font-semibold text-primary hover:underline`.
- **Pro user viewing 50-pack**: Same styling. Copy: "Elite gives you 150 Merits/month for $16.99 -- best value for power users". CTA: "[View Elite](/pricing)".
- **Elite user**: No banner on any pack.

### BillingPage (/settings/billing)

- **Layout**: Single column, max-width 768px, centered. Two sections stacked vertically with `gap-8` (32px).
- **CurrentPlanCard**: shadcn Card. Shows tier name (Badge), interval, price, Merit allowance, next renewal date. Two CTAs: "Change Plan" (Link to `/pricing`, text-primary) and "Cancel Subscription" (text-destructive, opens confirmation dialog or Stripe portal).
- **PurchaseHistoryTable**: shadcn Table component. Columns: Date (`text-sm`), Pack (`text-sm`, e.g., "25 Merits"), Amount (`text-sm`, e.g., "$9.99"), Status (Badge: "completed" green, "pending" amber, "failed" red). Sorted newest first. If > 20 rows, simple "Load more" button at bottom (not infinite scroll).
- **Empty purchase history**: "No purchases yet." with "Visit the Merit Shop" link to `/shop`.

### StripeCheckoutEmbed

- **Trigger**: User clicks "Get Pro", "Get Elite", or "Buy {N} Merits". Frontend calls `create-checkout-session` edge function with mode ('subscription' or 'payment') and plan/pack identifier. Receives `client_secret`.
- **Render**: `EmbeddedCheckout` from `@stripe/react-stripe-js` renders inside a Dialog (shadcn Dialog, max-width 560px). Dialog title: "Complete your purchase" for shop, "Subscribe to {Plan}" for subscriptions.
- **Loading**: Spinner (Loader2 icon, `animate-spin`) centered in dialog while client secret loads.
- **Success**: Dialog closes. For shop: toast "Merits added to your balance!" + `invalidateQueries(['merit-balance'])`. For subscription: redirect to `/dashboard` + toast "Welcome to {Tier}!".
- **Error**: Toast error from Sonner: "Payment could not be completed. Please try again."

### AppSidebar Updates

- **New entry "Merit Shop"**: Icon `Gem` (Lucide), label "Merit Shop", route `/shop`. Positioned after "History" and before "Settings" in the nav list.
- **New entry "Billing"**: Icon `CreditCard` (Lucide), label "Billing", route `/settings/billing`. Positioned after "Settings" (or as a sub-item of a Settings group).

## Accessibility

| Concern | Implementation |
|---------|----------------|
| Balance badge | `aria-label="Merit balance: {N} Merits"` on trigger button |
| Popover | Radix Popover handles focus trap and Escape dismiss automatically |
| Pricing toggle | Radix Tabs provides keyboard arrow navigation and ARIA roles |
| Disabled Analyze button | `aria-disabled="true"` + `title="Out of Merits"` |
| Savings badges | `aria-label="Save $17.98 with yearly billing"` |
| "Most Popular" badge | Decorative (no additional ARIA needed; visually clear) |
| Purchase history table | Standard HTML table semantics via shadcn Table (thead/tbody/tr/th/td) |
| Stripe checkout dialog | Radix Dialog handles focus trap; `aria-label="Complete your purchase"` |
| Color contrast | All text meets WCAG AA: primary on background (coral on black = 4.6:1), amber-500 on background (>4.5:1), destructive on background (>4.5:1) |
