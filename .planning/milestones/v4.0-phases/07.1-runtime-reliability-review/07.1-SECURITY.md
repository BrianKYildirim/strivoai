## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Client ↔ Edge Function (HTTP body) | Error responses returned to the browser | Generic error envelope only — no internal exception text / stack / provider payload |
| Edge Function ↔ Logs (stdout) | Structured `log.*` output captured by Supabase | Allow-listed fields only (feature, stage, userId-when-available, tier, provider/model, merit amount, retryable, errorCode, durationMs, reason-CODE) |
| Frontend parser ↔ Edge Function (wire contract) | `AiCreditsContext` byte-parses fixed error bodies | Frozen 401/402/429 shapes — must stay byte-identical |
| Operator/Claude ↔ Prod Supabase (MCP) | Read-only inspection of prod advisories/logs/schema | No write verbs; `apply_migration`/`db push` forbidden |
| Edge Function ↔ Anthropic provider | Upstream model responses | Raw provider payloads never logged or returned to client |
| Working tree ↔ tracked planning artifacts | Committed audit/register/residual docs | Names-not-values — no secrets/keys/PII/payment data recorded |
