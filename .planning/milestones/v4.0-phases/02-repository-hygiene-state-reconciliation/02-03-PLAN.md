- Risk: re-tracking a just-ignored path via a later `git add -f`. Mitigation: forbidden by CLAUDE.md + this phase; verify post-commit with `git check-ignore`.
- No real-secret exposure introduced. No HIGH findings (untracking is exposure-reducing).
</threat_model>
