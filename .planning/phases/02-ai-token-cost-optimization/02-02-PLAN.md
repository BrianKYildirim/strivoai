    Structure per RESEARCH §1 "Recommended seam design":
    - `const log = createLogger('ai-telemetry')` from `./logger.ts`.
    - Module-level `_client` and `_disabled` memo variables.
    - An internal `client()` that returns null immediately when `_disabled`, otherwise resolves
      `getServiceClient` via `await import('./supabase-client.ts')` inside a try/catch and memoises.
      The dynamic import is MANDATORY, not stylistic: `anthropic.ts` today imports only

      `npm:@supabase/supabase-js@2` into every offline Deno test that touches the Anthropic helper

      `Deno.env.get('AI_TEST_MODE')?.toLowerCase() === 'true'`. On insert error, `log.warn(
