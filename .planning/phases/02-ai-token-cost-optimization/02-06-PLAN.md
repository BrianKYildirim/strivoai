    editor after EACH run:
      select feature, tier, call_name, attempt, output_tokens, max_tokens, stop_reason,
             duration_ms, http_status, ok
      from public.ai_call_telemetry
      where created_at > now() - interval '15 minutes'
      order by created_at desc;
    Plus the expected row count per feature so a shortfall is obvious at a glance: Resume elite = 4
    parallel calls (criteria-1, criteria-2, summary, rewrites); Resume free = 1 (free-single);
    Career elite = 3 (base, growth, elite-extras) plus any `docx-extract`/`ocr-extract` utility rows;
    Career free = 1 (base); LinkedIn = 1 (linkedin-grade); Recruiting Lens elite = 3 (rl-call-1..3).

    Anomaly-handling rules, stated as rules not suggestions:
    - **ZERO rows for a run = a cache hit.** `analysis_cache` / `LINKEDIN_CACHE_VARIANT` /
      `RECRUITING_LENS_CACHE_VARIANT` return a stored result with NO Anthropic call and therefore NO
      telemetry. The run does not count. Re-run with a genuinely different input.
    - **`stop_reason = 'max_tokens'` on a TEMP-capped run** means that cell is deeply undersized and
      its true peak is UNKNOWN. Do not record `out == max_tokens` as the peak. Flag it; the cell needs
      a higher TEMP cap and a re-run.
    - **`http_status` 408 / an abort** is a MEASUREMENT FAILURE, not a data point (Pitfall 4: a raised
      token budget without a raised wall clock). Record it, flag it as a wall-clock finding for the
      report, and re-run.
    - **Attempt-2 rows** run at a different effective cap and must never be mixed into first-attempt
      statistics.

    Per-run table section — 21 empty rows with columns: run # | feature | tier | account | input
    description (length / density / sparsity) | rows written | stop_reasons seen | duration range |
    anomalies. Carry the account assignment across from `02-PREREQS.md` Section C: the 9 free-tier runs
    use the non-admin account (the admin email is force-elevated to elite by `_shared/auth.ts:155`),
    the 12 elite runs use the admin account.
