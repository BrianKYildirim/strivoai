## Trust Boundaries

| Boundary | Risk | Control |
|---|---|---|
| Stored Free analysis -> delta merger | A model patch may overwrite paid or Free-owned values | Pure missing-set allowlist, path-by-path construction, deep-preservation tests |
| Stored resume text -> Anthropic prompt | Stored text can contain prompt injection | Existing prompt sanitizer plus constrained delta-only schema |
| Anthropic response -> validated result | Malformed or overbroad JSON may reach persistence | Narrow patch validation, allowlisted merge, then complete-result validation |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-04-03 | Tampering | Delta patch and merger | mitigate | Reject protected or unrequested paths and prove the immutable projection by deep equality. |
| T-04-06 | Tampering | Stored resume prompt input | mitigate | Sanitize stored text and instruct the model to return only the generated delta schema. |
| T-04-09 | Information Disclosure | Validation and telemetry errors | mitigate | Log identifiers, path names, token counts, and status only; never resume, prompt, patch, or merged content. |
