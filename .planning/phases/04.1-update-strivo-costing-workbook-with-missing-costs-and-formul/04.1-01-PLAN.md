<objective>
Build the Wave 0 verification harness and prove that this Windows workspace has an approved workbook-editing, recalculation, cached-value, and rendering path before anyone mutates `docs/Strivo AI Final Costing Plan.xlsx`.

Purpose: CWB-02, CWB-12, CWB-13. This plan is read-only with respect to the in-scope workbook. It establishes the baseline coordinate/style/formula manifest and a failure-loud gate that all later work uses.

Execution mode: TDD false; MVP false; no product UI, schema, deployment, or configuration work.
</objective>

<threat_model>
ASVS Level 1; HIGH findings block the phase.

- **T-04.1-01 HIGH — formula/source injection:** source URLs, IDs, statuses, notes, and account evidence could be stored as executable formulas. The harness must restrict formulas to declared calculation ranges and fail on text-bearing formula cells or values beginning `=`, `+`, `-`, or `@` unless escaped as literal text.
- **T-04.1-02 HIGH — external code/data:** macros, OLE, workbook external links, data connections, or bracketed external-workbook formulas could execute or make costs non-reproducible. ZIP/package inspection rejects them.
- **T-04.1-03 HIGH — secret or PII disclosure:** billing evidence could leak API keys, customer identifiers, invoices, or environment values. The scanner permits only aggregate amounts and public source metadata, and rejects secret-like tokens and known secret variable names.
- **T-04.1-04 HIGH — formula drift/stale cache:** same-looking formulas may differ by scenario or retained cached values may be stale. Normalized coordinate/formula/style hashes, `CalculateFullRebuild`/headless recalculation, data-only reopen, and a later independent oracle are mandatory.
- **T-04.1-05 HIGH — corrupt replacement:** an interrupted save could replace the only deliverable. All probes open a GUID-named copy below the OS temp directory, verify ZIP integrity and reopens, and cleanup is constrained to that resolved child directory; the original is never written in this plan.
</threat_model>
