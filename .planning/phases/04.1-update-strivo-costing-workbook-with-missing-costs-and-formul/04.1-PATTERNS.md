#### Validation, errors, and source safety

- Add list validation for `Status` and `Include?`; only exact `Yes` activates cost, so malformed values fail closed.
- Store URLs, source IDs, notes, statuses, and account evidence as text. Escape strings beginning with `=`, `+`, `-`, or `@` rather than allowing them to become formulas.
- Permit formulas only in the declared calculated columns/ranges. Scan all other text-bearing ranges for formula injection.
- Use `IFERROR` only for ratio/zero-denominator handling. Never suppress a broken financial total to zero.
- Visible checks must return `OK` or a specific failure label such as `ERROR: user mix`, not an unlabeled boolean.
- No volatile formulas, circular references, macros, external workbook references, data connections, hidden assumptions, or alternate deliverable workbook.

function Invoke-PsqlBlock {
  param(
    [string]$Label,
    [string]$Sql
  )
  Write-Host "--- $Label ---"
  $tmpFile = [System.IO.Path]::GetTempFileName() + ".sql"
  try {
    [System.IO.File]::WriteAllText($tmpFile, $Sql, [System.Text.Encoding]::UTF8)
    & psql $DatabaseUrl -v ON_ERROR_STOP=1 -f $tmpFile

}

### Tooling and recalculation preflight

**Apply to:** Plan 01 and every mode that claims cached-value or visual correctness.

1. Check the spreadsheet artifact runtime first through its supported dependency loader. If the loader/runtime is unavailable, record that outcome; do not guess a package path or use bundled internals.
2. Probe Excel COM on this Windows host. Create `Excel.Application`, open only a temporary workbook copy, run `CalculateFullRebuild()`, save/reopen it, and export each sheet to PDF or another inspectable render.
3. If Excel COM is unavailable, probe `soffice`/LibreOffice headless for both recalculation/save and PDF rendering.
4. If neither a recalculation engine nor a rendering path works, `Tooling`, `Render`, and `Full` must fail with an actionable blocker. Workbook mutation must not begin.
5. Workbook-writing and formula-text inspection do not constitute recalculation proof. Reopen the recalculated file through a data-only reader and compare cached values to an independent oracle.

The repository has no existing Excel/OOXML implementation analog and no checked-in workbook-authoring dependency. Engine-specific implementation must therefore follow `04.1-RESEARCH.md` and the spreadsheet runtime's documented APIs rather than copying an unrelated code path.

### Static OOXML verification

**Apply to:** `Baseline`, `Quick`, `Security`, and `Full`.

- Open the `.xlsx` as a ZIP and run an integrity read over every entry.
- Require four visible worksheets in exact order after implementation.
- Reject `xl/externalLinks/`, connections, VBA, OLE objects, formulas containing external workbook references, `#REF!`, and secret-like text.
- Assert automatic/full recalculation metadata after the calculation engine saves the workbook.
- Hash normalized formulas with their coordinates and style IDs. Require identical scenario hashes and identical expected coordinate sets.
- Compare pre/post style signatures for preserved existing cells, and confirm new rows copy the nearest semantic style rather than introducing broad restyling.
- Validate OCR provider weights equal 100%, `Include?` validation exists, source/audit text cells are not formulas, and formulas exist only in approved calculated columns.

### Independent financial oracle and sensitivity

**Apply to:** `Oracle` and `Full`.

The PowerShell oracle must calculate outside Excel, using selected workbook input cells:

```text
gross billings
-> failed-payment loss
-> collected before refunds
-> refunded revenue
-> revenue after refunds
-> chargeback revenue loss
-> net collected revenue
```

It must separately reproduce subscription and Merit channels, successful-charge Stripe fees, annual amortization, dispute fees, vendor allowance/overage, OCR blends and volumes, retry-adjusted AI, total fixed/usage cost, profit, and founder allocation. Compare currency values within an explicit small tolerance; compare counts and visible `OK` states exactly.

Sensitivity runs must edit only temporary copies, mutate one named input at a time, force recalculation, and assert that expected dependents change while unrelated global assumptions and formulas remain unchanged.
