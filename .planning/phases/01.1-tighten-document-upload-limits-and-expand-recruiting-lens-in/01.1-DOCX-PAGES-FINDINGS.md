# Phase 01.1 DOCX Page-Metadata Findings

**Observed:** 2026-07-23  
**Source:** Direct operator inspection of exported `.docx` files and `docProps/app.xml`  
**Decision:** D-30(a) checkpoint satisfied

## Three-page export observations

| Generator | `<Pages>` present | Value | Matches true count | `<Words>` | Actual words |
| --- | --- | ---: | --- | ---: | ---: |
| Google Docs | No | unavailable | no value to compare | absent | 2,160 |
| Apple Pages | No | unavailable | no value to compare | absent | 2,160 |
| Microsoft Word | Supplemental observation only; see two-page calibration below | — | — | — | — |
| LibreOffice Writer | `NOT TESTED` | `NOT TESTED` | `NOT TESTED` | `NOT TESTED` | `NOT TESTED` |

Google Docs and Apple Pages both omit `<Pages>` and `<Words>` from
`docProps/app.xml` for the observed three-page export. The validator therefore
cannot use application metadata for these common generators and must fall back
to counting words from `word/document.xml`.

## Two-page calibration observation

| Generator | True content pages | `<Pages>` present/value | Matches true count | `<Words>` | Actual words |
| --- | ---: | --- | --- | ---: | ---: |
| Microsoft Office Word 16.0000 | 2 nonblank content pages | Yes / `3` | No — over-reports by one page | 859 | 1,440 |

The Word sample is important beyond calibration: a positive `<Pages>` value can
still be implausible. Blindly rejecting every document whose metadata says
`Pages > 2` would reject this observed two-page document. The validator must use
the extracted `word/document.xml` word count when metadata is absent, zero, or
contradictory, and must not use the embedded `<Words>` value as the backstop
count because it under-reported 1,440 actual words as 859.

## Conclusion

`DOCX_WORD_COUNT_BACKSTOP = 1600` is confirmed for the observed samples:

- The observed valid two-page Word document contains 1,440 actual words and
  remains below the 1,600-word acceptance boundary.
- The observed three-page Google Docs and Apple Pages document contains 2,160
  actual words and exceeds the boundary.

No threshold change is required for Plan 01.1-06. Its truth table must classify
the Word sample's `Pages = 3` metadata as implausible when the extracted actual
word count is at or below 1,600, preserving D-06's conservative ACCEPT
direction. This is evidence for the current threshold, not a claim that 1,600
is an exact page-count conversion for every document.
