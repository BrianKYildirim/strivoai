Build the deterministic pre-deploy proof layer: identical-byte parser parity plus local/mock browser integration for no-side-effect rejection, LinkedIn exemption, Recruiting Lens boundaries, responsive behavior, and accessibility.

Purpose: the repository deploy script runs the full baseline before it deploys a function. Therefore every test created here must be runnable before `validate-document` exists remotely. Live route, bundle, and production proof belong only to Plan 12.

</objective>

<threat_model>
- **Deployment circularity.** A test that calls the live validation route before deployment makes the deploy script's precondition impossible. Mitigation: `.local.ts` suites mock the function/network boundary and the config has no remote auth/global setup.
- **Mock vacuity.** A toast-only assertion can pass even if a component attempted storage or Merit work. Mitigation: mock spies cover each side-effect boundary and each rejection asserts exact zero calls; a valid control case proves the harness can observe positive calls.
- **Parser fixture drift.** Independently generated files can both report the expected count while differing in bytes. Mitigation: both runtimes regenerate one fixed-token fixture and assert the same SHA-256 manifest.
- **Responsive false confidence.** CSS source assertions alone do not prove layout. Mitigation: Playwright measures bounding boxes, scroll width, computed overflow, focus, accessible descriptions, and complete text at 320, 639, 640, 767, and desktop widths.
- **Accidental remote use.** Local suites must fail if an unmocked Supabase/function request escapes. No account, secret, external URL, paid AI call, or production project is used.
</threat_model>
