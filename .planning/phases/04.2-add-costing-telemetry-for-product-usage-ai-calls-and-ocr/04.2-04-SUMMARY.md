## Decisions Made

- The `feature_runs.run_variant` CHECK constraint shipped in 04.2-01 has no `analyze` value. Interview Prep analyze therefore records `standard` and evaluation records `evaluation`, which keeps the two separately countable under one canonical feature without a schema change.
- Where the shared analysis lifecycle executes a run, it already observes Merit and terminalizes; the handler only flushes the provider-attempt back-link so a run can never be terminalized twice.
- The resume stream re-derives the token from the same in-memory envelope Upload used, so the Upload -> Results navigation carries only the non-secret action nonce and never the token itself.

## Deviations from Plan

### Scope-honoring adjustments

**1. [Rule 3] Interview Prep variant naming follows the shipped schema**
- **Found during:** Task 3
- **Issue:** The plan asked for an explicit `analyze` variant, but the applied migration's CHECK constraint allows only `standard | cache_reuse | rerun | elite_unlock | evaluation`. Emitting `analyze` would have failed every insert.
- **Resolution:** Used `standard` for analyze and `evaluation` for evaluation; the acceptance criterion (separately countable variants under one canonical feature) is satisfied without a migration.
- **Files modified:** `interview-prep-analyze/index.ts`, `interview-prep-evaluate/index.ts`

**2. [Rule 3] Malformed LinkedIn bodies keep their original error shape**
- **Found during:** Task 2 review of the partial work
- **Issue:** The interrupted prior run parsed a body clone with a bare `await req.clone().json()` before the rate limit, moving a JSON-parse throw earlier than the existing contract.
- **Resolution:** The costing read now degrades to an empty object on parse failure, so downstream error ordering is byte-identical.
- **Files modified:** `supabase/functions/grade-linkedin/index.ts`

**3. Text-only surfaces left unwired**
- **Found during:** Task 4
- **Issue:** `RecruitingLens.tsx`, `InterviewPrep.tsx`, and `ActionFirstHero.tsx` perform no authenticated browser extraction; `ActionFirstHero` runs pre-auth, where `begin-feature-run` cannot mint a token.
- **Resolution:** These surfaces rely on the backend boundary, which the plan explicitly permits for text-only requests. The wiring test asserts this positively rather than leaving it implicit.
- **Files modified:** none

**4. Unrelated working-tree work preserved**
- **Found during:** All tasks
- **Issue:** An in-progress Recruiting Lens account-state debug investigation occupies several frontend files, one of which appears in this plan's file list.
- **Resolution:** No debug file was reverted, staged, or committed; `RecruitingLens.tsx` needed no costing edit, so it was left untouched.
- **Files modified:** none
