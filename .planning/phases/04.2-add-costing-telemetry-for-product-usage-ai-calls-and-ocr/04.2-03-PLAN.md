<threat_model>
## Trust Boundaries

| Boundary | Risk | Control |
|---|---|---|
| Browser -> begin-feature-run/ocr-pdf | Forged run identity or costing fields | Auth, strict envelope, opaque expiring token, server snapshot lookup |
| Raw documents/images -> telemetry | Sensitive content leakage | Typed metadata allowlist; no bytes/text/images/prompts/responses persisted |
| OCR provider -> cost/page fields | Unattributable values treated as measured | Preserve evidence and mark missing billing/page facts unknown |
| Claude OCR -> joined reports | Same provider spend counted twice | AI row owns cost; document row stores only reference |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-04.2-11 | Spoofing | Correlation token | mitigate | Signed/server-resolved short lifetime, owner and state checks. |
| T-04.2-12 | Information Disclosure | Document telemetry | mitigate | Metadata allowlist and safe controlled errors only. |
| T-04.2-13 | Tampering | Provider pages/cost | mitigate | Server/provider evidence only; unknown when attribution is absent. |
| T-04.2-14 | Repudiation | OCR route/attempts | mitigate | One document event plus ordered provider attempt metadata and request IDs. |
| T-04.2-15 | Tampering | Claude cost ownership | mitigate | Foreign-key reference to the sole AI telemetry cost row. |
</threat_model>
