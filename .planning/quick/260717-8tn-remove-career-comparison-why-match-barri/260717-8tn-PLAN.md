# Quick Task: Retire Career Comparison extras, Skills Gap Analysis, and Compare Jobs

Remove the named Career Comparison sections from both generation and display, remove all
multi-role comparison entry points, and retire the standalone Skills Gap Analysis / Compare
Jobs product surfaces end-to-end. Preserve unrelated Career Compass content: specifically,
`careerFields[].whyMatch` / `whyMatchDetails`, role-card `skillGaps`, readiness `gaps`, and
roadmap actions remain valid descriptive data rather than standalone retired features.

The working tree already contains concurrent Elite schema/debug work in several Career
Compass backend files. Preserve it and make focused edits; do not revert, reformat, or
overwrite unrelated changes. Do not edit historical migration files or generated database
types merely to erase legacy enum values: those values may remain as database-history
compatibility, but no active code may create, invoke, advertise, or display either feature.
