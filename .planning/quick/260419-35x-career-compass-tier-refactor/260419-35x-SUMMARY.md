# Quick 260419-35x: Career Compass free-tier refactor + tier locks + layout

Free-tier Career Compass now sources its output from prior Resume Analysis + LinkedIn Grader rows through a single sub-4000-token Anthropic call, returns HTTP 412 before any merit deduction when either prior analysis is missing, and mirrors Resume Analysis's `BlurredLockCard` lock UX on every tab. Results view width aligned to `max-w-5xl` to match `Results.tsx`. Pro/Elite parallel fan-out is byte-identical.

## Task-by-task

- `supabase/functions/_shared/career-prompts.ts`
  - Added `export const FREE_SINGLE_CALL_MAX_TOKENS = 4000;`

  - Updated fixture (2 roles, 2 roleRoadmaps) and free-tier assertions
