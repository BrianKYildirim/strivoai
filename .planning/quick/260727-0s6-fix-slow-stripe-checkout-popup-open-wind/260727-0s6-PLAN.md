<objective>
Make both Stripe checkout entry points ("Upgrade to Elite" / "Get Elite" and "Buy X Merits")
render visible checkout UI on the same tick as the click, replacing several seconds of dead
time with an explicit "Preparing secure checkout…" state, guaranteeing exactly one Stripe
session per click, and closing the dialog cleanly on every non-embedded outcome.

Purpose: today `Pricing.tsx handleTierCta` awaits the full `create-checkout-session` edge
round trip (auth + Stripe session creation + possible cold start) and only then calls
`setCheckoutOpen(true)`, and `StripeCheckoutWrapper` hard-returns `null` when `clientSecret`
is null — so nothing at all can be shown while the request is in flight. Repeated clicks in
that dead window create multiple Stripe sessions.

Output: perceived-instant checkout open on both flows, with click de-duplication and
controlled failure handling. Payment confirmation, `return_url`s, webhooks and the edge
function are untouched.
</objective>
