"Test timed out in 5000ms"; in isolation it passes. The cause is an unnecessary
`vi.resetModules()` + per-test dynamic `await import('@/pages/AnalysisHistory')` that

render already controls the flag. The dynamic re-import is pure overhead and can be removed.

v4.0 deferred backlog.
